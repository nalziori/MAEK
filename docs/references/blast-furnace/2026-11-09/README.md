# 글로벌 공개자료 기반 고로 배관 계통 검토 — 2026-11-09

MAEK 모델 보완의 첫 기준으로 고로 냉각수 공급/회수 계통도를 권고한다. 이 순서는 공개 자료와
현재 시연 목적에 따른 개발 판단이다. 공식 전사 위험 순위가 아니며, 실제 가스 누출 등 급박한
안전 위험은 설비 계통과 무관하게 우선 검토해야 한다. BFG 회수·정제 계통과 열풍 계통도 핵심이다.

## 확보하고 확인한 자료

- worldsteel의 2011년 보고서 PDF 73쪽 / 인쇄 66쪽, Figure 2.1.1: Oyak Isdemir 고로 냉각수 계통도.
  노저 스테이브 A, 동 스테이브 B, 풍구 C가 독립 폐회로이고 열교환기로 공통 2차 냉각수와 분리된다.
  탈염수·질소 가압·공통 비상 및 보충수 연결을 설명한다. 도면과 본문을 렌더로 확인했다.
  공급 40°C, 회수 A 45°C / B 52.5°C / C 47.5°C가 표기되어 있다.
  유량 표기는 열교환기당 용량과 2+1 구성이므로 개별 배관 실측 유량이나 회로 총량으로 복사하지 않는다.
- Primetals 동 스테이브 공식 기술 페이지: 냉각관 연결 손상·마모에 의한 노내 유입과 노체 손상 가능성을 설명한다.
- Primetals/ArcelorMittal Poland 공식 프로젝트 발표: 사이클론과 습식 세정기의 적용 사례.
- Danieli 공식 열풍로 기술 설명 및 SSAB Stove 47 PDF: 열풍로의 순환 가열·송풍과 열팽창/열응력 관련 구조 설명.

원문 링크와 검증 범위는 verified_evidence.json, 다운로드 해시는 sources.json에 기록했다.
Primetals 구형 종합 PDF와 Paul Wurth Hamborn PDF는 현재 주소에서 유효한 원본을 확보하지 못했으므로
로컬 확보 자료로 표시하지 않았다. 확인되지 않은 검색 스니펫의 설계값은 채택하지 않았다.

## MAEK에 적용할 계통도

현재 모델: 열교환기→펌프→공급 환상관→스테이브→회수 환상관→열교환기.
보완 기준: 열제거 경로와 고로측 1차 폐회로를 분리하고, 노저/동 스테이브/풍구별 회로를 구분한다.
탱크 질소 가압은 물과 질소를 같은 액체 배관으로 혼합 연결하는 방식이 아니다.
비상·보충수, 예비 펌프/열교환기 가용성, 차단 상태, 배관과 공정 영향의 연결 정보를 명시해야 한다.
계측 후보는 회로별 유량, 공급/회수 온도, 압력과 누설 근거다. 구체적인 경보값은 현장 설계 자료가 필요하다.

MAEK 관측 순서: 외부 배관 RGB/열화상 관측→품질·위치 확인→후속 검사 후보→
안전 등급을 먼저 반영하고 동일 등급 안에서 연결 회로의 중요도와 대체 공급 여부 비교.
외부 RGB 표식으로 노내 스테이브 누수나 균열을 확정해서는 안 된다.

## 자료 사용 범위

공개 PFD/사례도와 기술 설명을 확보한 것이며 실제 P&ID, 밸브 태그·관경·설계압력,
시계열 센서 데이터나 결함 정답 데이터셋을 확보한 것은 아니다. 사업장별 사례값을
포스코 또는 현재 축약 모델의 경계조건에 그대로 대입하지 않는다.
worldsteel PDF에는 All Rights Reserved와 재현 허가 안내가 있다. PDF·그림 공개 재배포 권한을
획득한 것으로 간주하지 않으며 발표물에는 원문 링크와 자체 요약 계통도를 우선 사용한다.
이번 작업은 참고자료 확보이며 Unity 장면과 Windows 실행본은 변경하지 않았다.
