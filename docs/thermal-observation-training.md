# 실측 없는 단계의 열화상 학습: 관측 변화부터 검증

MAEK의 목적은 가스 배관의 균열·감육 위험을 조기에 선별하여 사고 예방과 검사비 절감을 지원하는 것이다. 이 문서는 그중 **열적 관측을 제공하는 하위 기능**의 합성 사전학습을 정의한다. 열화상만으로 두께·균열 진행·잔여수명·안전을 판정하는 모델은 아니다.

## 이번에 학습할 수 있는 것

같은 위치의 기준 영상과 현재 영상에서 **측정 가능한 겉보기 온도 변화 영역**을 분할한다. 완전히 정합된 두 float32 온도 영상이 입력이다. 기준 영상 없이 현재 영상만으로 같은 기능을 수행한다고 주장하지 않는다. 기존 3클래스 YOLO의 라벨 체계와는 다르므로 그 학습 명령에 그대로 넣지 않는다.

입력은 `[asinh((reference-25)/50), asinh((current-25)/50), asinh((current-reference)/2)]`의 3채널이다. 촬영별 min-max 정규화나 −40~200°C를 8비트로 압축하는 전처리를 쓰지 않는다. 원인·두께·깨끗한 영상·정답 마스크는 모델 입력에서 제외한다.

정답은 센서 PSF·양자화·포화를 적용한 **잡음 없는** 두 영상의 온도차로 계산한다. 모델이 보는 두 영상에는 서로 독립적인 센서 잡음을 넣는다.

- `0`: 차이가 `max(√2σ, 양자화간격)` 이하. **결함 없음이나 안전이라는 뜻이 아니다.**
- `1`: 차이가 `max(3√2σ, 2×양자화간격)` 이상. 반사·방사율·열전달 등 원인은 구분하지 않는다.
- `255`: 두 임계값 사이의 약한 신호, 포화, 불량 픽셀. 손실함수에서 제외한다.

σ는 합성 카메라에서 가정한 잡음 표준편차다. 이 임계값은 현장 검출한계·POD·진단 기준이 아니다. 픽셀 오경보율과 영상 전체 경보율은 별도로 확인한다. 라벨이 차이의 임계값에 기반하므로 신경망 학습 전에 단순 차이·평활 차이 규칙과 비교할 필요가 있다.

## 생성 구조와 증강

원통 내부막·금속벽·보온재·외부막의 열저항에 금속벽의 2차원 면내 열전도를 더한 정상상태 얇은 셸 근사다. 해석해 일치, 최대원리, 에너지 보존, 열 확산 및 격자 수렴을 단위검사한다. 수치 검사 통과가 실제 배관 모델 보정을 뜻하지는 않는다.

각 장면에 다음 5가지 쌍을 만든다: 동일 상태 반복 촬영, 내부 감육, 국부 외부 열전달 변화, 주변 반사 변화, 표면 방사율 변화. 모든 원인에 같은 관측 정답 규칙을 적용한다. 감육 신호가 작으면 양성으로 강제하지 않는다.

보온 유무 × 방사율 2구간 × 온도 구동력 2구간 × 잡음 2구간의 16조합을 모든 분할에서 교차한다. 추가로 온도차 부호·위치·크기·배관 방향·벽 두께·열전도율·내부 열전달·배관 지름·PSF를 바꾼다. 물리 원인에 따른 경계 모양을 고정하지 않으며, 배경과 표면 질감은 기준/현재에 공통으로 넣는다.

| 분할 | 독립 장면 | 영상 쌍 | 사용 목적 |
|---|---:|---:|---|
| train | 128 | 640 | 학습 |
| dev | 32 | 160 | 규칙 비교·설정 선택 |
| test | 32 | 160 | 동결된 모델의 최종 평가 |
| stress | 32 | 160 | 잡음·흐림·지름이 다른 합성 악조건 평가 |

같은 장면의 모든 변형은 같은 분할에 둔다. test/stress는 이번에 무결성·라벨 분포만 검사하고 모델 선택에는 사용하지 않는다. 분할은 새 설비의 실측 검증을 대신하지 않는다. 5원인을 같은 비율로 만든 것은 실험 설계이며 실제 발생 빈도가 아니다.

## 통과해야 하는 검사

1. 수식·수치: 평형, 해석해, 보존, 확산 및 수렴.
2. 센서·정답: 독립 잡음, 포화/불량 픽셀 무시, 저장 배열에서 정답 전수 재계산.
3. 분포·누수: 장면 분할, 입력 해시, 16조건 교차, 원인별 신호/보류 비율.
4. 학습 경로: 검증 파일과 manifest/protocol/index 해시 연결, 실제 배치 입력 및 CPU 역전파 한 번.

이 검사를 통과한 데이터만 `synthetic_registered_thermal_change_segmentation` 범위로 사용한다. `field_validated=false`, `crack_training_eligible=false`는 유지한다. 필수검사 보존 사례는 요구사항 fixture이며, 통합 검사 경로를 실제로 검증했다는 뜻이 아니다.

## 명시적인 한계와 다음 검증

완벽한 영상 정합과 동일 카메라 보정을 가정한다. 현재 배관은 3차원 투영이 아닌 펼친 직사각형 표면이며, 광학 블러는 겉보기 온도 공간 근사다. 회색체 근사에는 실제 센서의 파장 응답·대기 투과가 없다. 방사율 변화는 관측 방사량만 바꾸고 외부 열전달 계수의 에너지수지에는 되먹임하지 않는다. 열응력, 시간에 따른 균열 성장, 실제 가스 분광·누출 물리는 없다.

다음 실험은 dev에서 단순 규칙 대비 학습 모델의 **같은 오경보 예산에서 관측 변화 재현율·IoU·보류율**을 비교하는 것이다. 이때 규칙이 아는 카메라 잡음 조건을 모델에도 어떻게 제공할지 고정해야 한다. 모델이 합성 규칙보다 유리하지 않다면 신경망을 채택할 이유가 없다. 그 다음 새로운 물리 모델/센서 변화로 생성기 간 일반화를 시험한다. 시험 데이터를 보고 설정을 바꾸면 새 시험 세트를 만들어야 한다.

현장 도입 전에는 제어 가능한 시편·온도·반사·거리·촬영각·운전 조건으로 측정값과 생성값을 맞춰야 한다. 같은 위치의 UT/두께/균열 검사 결과를 연결한 후, 위험정보+RGB 대비 열화상 추가가 같은 검사비로 결함 누락을 줄이는지 검증한다. 현재 이 결론을 낼 실측 자료는 없다.

## 재현과 사용

MAEK 저장소에서 실행한다. 출력 폴더가 있으면 생성기는 덮어쓰기를 거부한다.

```powershell
.venv/Scripts/python.exe scripts/generate_thermal_observation_dataset.py --out ../outputs/maek-c/thermal-observation-new
.venv/Scripts/python.exe scripts/validate_thermal_observation_dataset.py --help
.venv-benchmark/Scripts/python.exe scripts/smoke_thermal_observation_training.py --help
```

```python
from maek.thermal_observation_data import ThermalObservationDataset
dataset = ThermalObservationDataset('PATH_TO_DATASET', 'train')
item = dataset[0]  # input (3,H,W), target (H,W); CrossEntropyLoss(ignore_index=255)
```

생성·검증과 작은 학습 경로 검사는 CPU에서 수행한다. 본격적인 모델 학습과 반복 비교에는 Colab GPU를 사용하면 된다. 이번 데이터 생성 단계에서는 Colab 학습을 실행하지 않는다.
