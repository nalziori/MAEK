# MAEK 배관 점검 대시보드

패드용 정적 웹 화면입니다. **조치가 필요한 배관 ID·의심 사유·지도 위치**를 먼저 확인하고, 같은 배관의 RGB/열화상 관측과 현장 비파괴검사 결과를 이어서 봅니다.

## 실행

저장소 루트에서 실행합니다. 빌드·백엔드·npm 설치 없이 화면을 볼 수 있습니다.

```sh
python -m http.server 8877 --bind 127.0.0.1 --directory dashboard
```

http://127.0.0.1:8877/index.html 에 접속합니다.

## 화면과 조작

- 통합 점검: 부식 의심 배관 16개, 같은 번호의 지도 표식, 선택 배관의 RGB·열화상·비파괴검사 결과.
- 지도: 방문 구역, 배관별 방문 경로, 현재 위치. +/−·전체·끌기·휠·두 손가락 확대·지도 크게 보기.
- 영상: 눌러 크게 보기, 원본 비율과 후보 영역 유지, 닫기/Escape로 복귀.
- 배관 조회: 한 번의 검색·필터로 배관 선택, 최신 결과와 현장검사 기록 확인, 지도 위치로 이동. 선택과 검색 조건은 화면을 오갈 때 유지합니다.

## 데이터 범위

Unity 가상 제철소의 저장 시연 자료입니다. 배관 247개·분석 촬영 771개·RGB 후보 배관 16개를 포함합니다. 배관별 대표 RGB 247개는 촬영 메타데이터·분석 응답·요청 ID·PNG 해시와 대조했습니다. 표시는 대상 배관에 매핑된 RGB 색상 규칙 후보이며 확정 결함·위험 순위가 아닙니다.

**현재 위치와 방문 경로는 저장 계획 순서를 재구성한 것**입니다. 실시간 드론·실제 제철소 도면과 연결되지 않았습니다. 배관 사이 전이 로그가 없는 구간은 직선으로 이어 그리지 않습니다.

같은 배관의 열화상 자료는 미연결로 표시합니다. 별도 합성 열 자료를 동일 위치로 대신 표시하지 않습니다. RGB/열 관측 미검출과 정밀검사 미접수는 정상·안전 판정이 아닙니다.

`operations-data.js`와 `inspection-evidence.js`는 자체 포함된 시연 스냅샷입니다. 실행 시 저장소의 Unity/Python 분석 모듈이나 원본 촬영 폴더를 요구하지 않습니다. 원천 경로와 SHA256는 스냅샷에 기록되어 있습니다.

## 비파괴검사 결과 연결

선택한 배관에서 **결과 연결**을 누르고 다음 필드가 있는 JSON을 선택합니다.

`result_id`, `pipe_id`, `inspection_point`, `method`, `performed_at`, `inspector`, `result_summary`, `procedure_ref`, `coverage_ref`, `report_ref`.

모든 필드는 비어 있지 않은 문자열이며 `performed_at`에는 시간대가 포함되어야 합니다. `pipe_id`는 선택 배관 ID와 같아야 합니다. 다른 배관, 누락된 항목, 다른 내용의 중복 결과 ID를 거부합니다.

결과는 해당 브라우저 기기의 **localStorage**에 저장되고 검토 대기로 표시됩니다. 중앙 시스템·계측 장비·서명·작업 허가와 연동하지 않습니다. 보고서의 검사 부위를 표시하지만 영상 표면과의 정확한 정합은 별도 확인이 필요합니다. 다른 브라우저에서 공유되는 운영 검사 이력이 아닙니다.

## 검증

Chrome/Chromium, Node.js 22 이상, npm이 필요합니다. 서버를 실행한 상태에서 별도 터미널을 엽니다.

```sh
cd dashboard
npm ci
npm test
```

기본 Chrome 경로가 다르면 `CHROME_PATH`, 다른 서버 주소를 사용하면 `MAEK_DASHBOARD_ORIGIN` 환경변수를 지정합니다. 브라우저 자동 다운로드는 하지 않습니다.

- 문제 배관 16개·지도/목록 연결·같은 배관 근거·NDT 오연결 및 충돌 방지.
- 패드 1024×768·1194×834·768×1024의 기본 화면 스크롤 없음.
- 지도 확대/축소·끌기·휠·핀치·큰 지도·RGB 확대와 초점 복귀.
- 검사 보고서는 명시적인 UI 시험용 자료를 사용하고, 시험 브라우저의 저장 데이터는 종료 시 지웁니다.

생성 캡처·시험 보고서·개발 캐시는 `.hallmark/`에 기록하며 Git에서 제외합니다. 실제 현장 사용자 시험과 실물 센서 검증은 이 변경에 포함되지 않습니다.

## 글꼴

Pretendard Variable v1.3.9를 로컬에서 제공합니다. 라이선스와 공식 배포 출처는 `assets/fonts/OFL.txt`, `assets/fonts/source.json`에 포함되어 있습니다.

기본 지도는 패드에서 문제 배관과 방문 구역·동선을 대조하기 위한 2D 평면도입니다. PR #33의 입체 설비 표현은 주 화면의 정보량을 줄이기 위해 되돌렸습니다. 원본 모델의 XYZ 자료는 유지합니다.

지도는 선택 배관을 중앙에 두고 기본 220%로 시작합니다. 다른 배관을 선택하면 해당 위치로 맞추며, 선택 표식은 짙은 갈색으로 구분합니다. 카메라는 지도 영역의 가로세로 비율에 맞춰 여백을 줄입니다. 전체 맞춤은 전체 구역 100%로 돌아가고, 수동 확대·이동은 같은 배관을 보는 동안 유지됩니다.

선택 배관의 높이는 모델 지면 0m 기준 **배관 경로(중심선)의 최소–최대 높이**입니다. 작은 수직 눈금은 모든 배관에 같은 축을 사용합니다. 배관 외곽 치수·작업 발판·드론 고도가 아니며, 정확한 확인 지점 높이는 좌표가 연결되기 전까지 미연결로 표시합니다.

지도 제목 행을 없애고 확대 버튼을 지도 안에 배치합니다. 지도 조작의 위치 맞춤 버튼은 선택 배관으로 이동합니다. 지도 아래 중복 위치 정보와 이동 버튼은 제거하고 방문 구역 요약만 유지합니다. 목록의 선택 행은 테두리·배경과 `aria-current`로 표시하며, 배관 조회에서 선택 후에도 키보드 초점을 유지합니다. 배관 조회의 조치 필요 필터는 RGB 후보 배관만 표시합니다.

메뉴·조작 아이콘은 18px이며 터치 버튼은 44px 이상을 유지합니다. 지도 크기 스타일은 지도 루트 SVG에만 적용하여 버튼 아이콘의 과대 확대를 방지합니다. 지도와 번호 표식에도 키보드 초점을 표시합니다. 접근성 개선은 W3C의 [초점 표시](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html), [터치 영역 강화](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html), [정보와 관계](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html)를 참고했으며, 전체 WCAG 준수 인증을 의미하지 않습니다.

확대·전체 보기·위치 맞춤·이전/다음·닫기는 아이콘과 접근성 이름을 사용하며, 터치 영역은 최소 44px입니다. 배관 ID·의심 사유·높이·검사 상태는 글자로 유지합니다. `npm run test:height`로 높이 범위·공통 축·아이콘 이름과 지도 확대 시 아이콘 보존을 확인합니다.


## 통합 배관 조회

메뉴는 통합 점검(`tab=home`)과 배관 조회(`tab=pipes`) 두 개입니다. 기존 `tab=areas`와 `tab=records` 링크도 같은 배관을 유지한 채 조회 화면으로 연결됩니다.

조회는 목록과 선택 배관 상세를 나란히 표시합니다. 최신 현장검사 결과는 검사 시각(`performed_at`)으로 정렬하며, 늦게 접수된 과거 결과가 최신 결과를 덮어쓰지 않습니다. 전체 현장검사 기록과 드론 촬영 근거 ID는 접힌 상세 영역에 보존합니다. 드론 촬영별 날짜는 현재 스냅샷에 없으므로 임의로 표시하지 않습니다. 현장검사 원본 보고서의 검사 범위·절차·보고서 참조는 기록을 펼치면 볼 수 있습니다.

이 구성은 [정보를 외우지 않고 화면에서 확인하도록 하는 원칙](https://www.nngroup.com/articles/recognition-and-recall/)과 [점진적 공개](https://www.nngroup.com/articles/progressive-disclosure/)를 참고했습니다. 패드의 기본 화면은 문서 스크롤 없이 표시하고, 펼친 긴 기록은 상세 영역 안에서 스크롤합니다. 실제 현장 작업자 시험은 별도입니다.
