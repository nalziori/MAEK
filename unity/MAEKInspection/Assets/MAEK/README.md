# 배관 압력·유량 및 고로 CFD 연동

현재 시작 장면: `Assets/MAEK/Scenes/MAEKHydraulicCFD.unity`.
247개 배관의 계산 압력·유량과 방향을 표시합니다. Y: 세 계산 사례 전환, V: 흐름 표시.
P로 CFD를 열면 충전층 압력·유속 및 새 노저부 다상 해석을 볼 수 있습니다.
가정 운전조건으로 계산한 결과를 재생하며, 실제 현장값이나 실시간 OpenFOAM 해석이 아닙니다.
상부는 압력·유량 양방향 정상상태 연결, 노저부는 단방향 경계조건 연결입니다.
설정·재계산·검증 범위는 `HYDRAULIC_CFD_GUIDE.md`를 확인하세요.

# 배관 용도·계통 시연 장면

이전 용도 표시 장면: `Assets/MAEK/Scenes/MAEKPipeServices.unity`.
247개 배관을 14개 용도로 구분합니다. E: 배관 선택, L: 계통 색상, M: 정보 패널.
오른쪽 패널에서 계통과 배관을 고르고 검사 카메라를 이동할 수 있습니다.
추가된 질소·계장공기는 별도의 가상 시험 모듈입니다. `PIPE_SERVICES_GUIDE.md`를 확인하세요.
기존 CFD 장면과 검사 경로도 보존되어 있으며 P로 CFD와 외관 검사를 전환합니다.

# 3D CFD 시연 장면

CFD 전용 장면: Scenes/MAEKFurnaceCFD.unity. H: 노저부, S: 상부 반응층, P: 보행·드론 복귀. 계산 결과 재생과 제한은 CFD_GUIDE.md를 확인하세요.

# MAEK — 배관 점검과 고로 물리 모델

이전 축약 모델 장면: `Assets/MAEK/Scenes/MAEKFurnacePhysics.unity`. Play하면 고로 단면과 용선 유동 화면으로 시작합니다. **P**로 보행·드론 모드로 돌아가며, 고로 화면에서는 **1/2**로 고로를 선택합니다. 출선구 개폐와 공급 조건은 화면에서 조작합니다.

반응 질량·열수지, 순철 대용 물성의 용융 잠열, 압력·마찰에 따른 출선, 1차원 수로의 수심·유속을 계산합니다. 실제 조성의 다상 CFD를 포함하지 않는 실시간 축약 모델입니다. 가정·출처·검증 범위는 `FURNACE_PHYSICS_GUIDE.md`를 읽어주세요.

# MAEK 배관 연결 수정 및 가상 드론 점검

기존 연결 검증 장면은 `maek_drone_verified.blend`와 Unity `Assets/MAEK/Scenes/MAEKDroneInspection.unity`입니다. 기존 interior_ready 모델은 수정 전 비교용으로 보존했습니다.

## 수정 내용
- 배관 끝 좌표만 비교하던 검사를 실제 평가 메시의 단면 둘레 검사로 보완했습니다.
- 설비 곡면·비스듬한 접면에 맞춘 노즐, 배관 분기·꺾임의 접속 피팅을 추가했습니다.
- 두 세정탑 상단 배관은 수직 인출 후 곡관으로 이어지도록 수정했습니다.
- 두 굴뚝의 접속점은 굴뚝 중심에서 실제 외벽의 유입면으로 옮겼습니다.
- 원형 플랜지·밴드는 닫힌 곡선으로 바꾸어 끝 이음의 검은 틈을 없앴습니다.

## Unity 사용
`MAEKDroneInspection` 장면을 열고 Play합니다.
- F: 보행 / 가상 드론 시점 전환
- 왼쪽·오른쪽 화살표: 이전·다음 배관 (배관 간에는 카메라 컷 전환)
- Space: 비행 일시정지 / 재개
- 자동으로 현재 배관을 따라간 다음 다음 배관을 점검합니다.
- 비행 속도 기본값 2 m/s. 런타임 SphereCast에 장애물이 감지되면 정지합니다.
- 보행 모드는 WASD, 클릭으로 마우스 시점 고정, Esc로 해제합니다.

## Blender 사용
`11_Drone_inspection_cameras` 컬렉션의 `DRONE <배관 ID>` 카메라를 선택합니다. Ctrl+Num0으로 활성 카메라로 지정하고 프레임 1부터 재생합니다. 각 카메라의 `flight_end_frame` 속성이 해당 비행의 끝 프레임입니다. 각 배관은 별도 출발 경로이며 배관 사이 이동은 비행 검사 대상이 아닙니다.

## 검증 근거
- `mesh_endpoints_before.json`, `mesh_endpoints_after.json`: 배관 240개, 양 끝 480곳의 실제 메시 둘레 검사. 설비 노즐 뒤쪽 64점의 외벽 접합도 확인합니다.
- `drone_connectivity_report.json`: 배관 그래프 및 62개 공정 경로, 다른 배관과의 간섭 검사.
- `drone_overlap_report.json`: 등록된 접속부 외의 다른 설비와의 형상 간섭 검사.
- `drone_flight_report.json`: 반경 0.12 m 가상 소형 드론의 비행 경로 검사. 배관을 볼 수 있는 정지점을 선택하고, 지점 사이 경로는 최대 0.18 m 간격으로 보수적인 표면 여유 거리를 검사합니다.
- `unity_drone_report.json`: Unity 엔진에서 각 경로를 SphereCast/CheckSphere로 다시 검사하고 기존 보행·장비 충돌 검사도 수행합니다.

실제 드론 비행 실험이나 공력 시뮬레이션이 아닌 가상 카메라 점검입니다. 실제 포스코 도면이 없는 시연용 배치이며 압력·유량 및 설계 규격의 적합성을 검증한 모델은 아닙니다. 설비 내부의 유체 통로는 공정 그래프로 표현하고 외형 메시로 재현하지 않습니다.
