# 학습 전략: 녹 비전, 열화상 비전, 초음파 신호 분석

MAEK의 학습 모델은 세 종류입니다. 셋 다 실제 점검 데이터가 없으므로 물리 기반 합성 데이터로 먼저 학습하고, 실제 데이터가 조금이라도 생기면 그것으로 보정합니다.

| | 녹 비전 (일반 카메라) | 열화상 비전 | 초음파 신호 분석 |
|---|---|---|---|
| 찾는 것 | 외부 녹, 보온 외장 얼룩·파손, 누설 흔적 | 젖은 보온재, 보온 탈락, 증기 누설 | 두께, 균열, 내부 피팅 |
| 입력 | 사진 (RGB) | 온도값이 그대로 담긴 원본 열화상 | A-scan 파형 |
| 모델 | 소형 YOLO-seg (사전학습 가중치에서 시작) | 배관 축 방향 배경 대비 온도차 + 소형 분할 모델 | 두께는 신호처리, 피팅은 소형 MLP + 적응 임계값, 균열은 게이트 규칙 |
| 합성 데이터 | `python -m maek render2d` | `python -m maek thermal` | `python -m maek ut` |
| 실제 데이터 보정 | 공개 실사 부식 사진, 현장 사진 소량 | 방사율 기준 테이프, 보온재 개방 확인 | 두께 기준 블록, 인공 결함 블록 |

## 공통 원칙

- **어려운 조건은 평가에만 씁니다.** `shifted` 데이터는 학습에도, 모델·임계값 선택에도 쓰지 않습니다. 고를 때는 일부러 조건을 넓게 흔든 별도 검증 데이터(도메인 랜덤화)를 씁니다.
- **배관 구간 단위로 나눕니다.** 학습과 검증을 `segment_id` 기준으로 나눠 같은 배관 사진이 양쪽에 섞이지 않게 합니다.
- **결함 단위로 평가합니다.** 픽셀 정확도 대신 결함을 찾았는지(hit/miss)로 POD 곡선과 a90을 구하고, km당 오경보 수를 같이 봅니다. 기준은 MIL-HDBK-1823A의 hit/miss 방식입니다.
- **임계값은 목표 오경보율에 맞춥니다.** 조건(신호 세기, 조명)별로 따로 정합니다. 초음파 피팅 검출기에서 이 방식으로 오경보를 30~49%에서 0.7%로 줄였습니다([결과](results.md)).
- **물리를 잘 아는 순서로 현실 적용이 쉽습니다.** 초음파가 가장 쉽고, 열화상, 일반 카메라 순입니다. 물리가 단순할수록 합성 데이터가 현실과 비슷합니다.
- **사람이 확인할 수 있게 근거를 같이 냅니다.** 마스크, 온도차 지도, 파형과 게이트를 함께 보여 줍니다.

## 1. 녹 비전 (기능 ①)

**데이터**
- 합성: 2D 합성 렌더러로 부식 패치, CUI 외장 얼룩, 플랜지 누설 흔적을 그리고 마스크와 YOLO-seg 라벨을 만듭니다.
- 공개 실사: 버지니아공대 교량 강재 부식 분할 데이터셋(440장, 상태 4등급)을 씁니다. 등급을 우리 클래스(부식)로 바꿔 씁니다. 배관이 아니라 교량이므로 질감·색 학습용입니다.
- 현장: 해커톤이나 실증에서 사진을 받으면 수십 장만이라도 라벨을 붙여 마지막에 추가 학습합니다.

**학습 순서**
1. COCO 사전학습 YOLO-seg 소형 모델(n 크기)에서 시작합니다.
2. 합성 데이터로 학습합니다. 조명, 분진, 증기, 흔들림 블러, 센서 잡음, 시점을 무작위로 바꿉니다.
3. 공개 실사 데이터를 섞어 추가 학습합니다. 합성만으로 배운 모델이 실사에서 얼마나 떨어지는지 먼저 재서 기록합니다.
4. 임계값을 km당 오경보 목표에 맞춥니다.

**헷갈리는 비결함 사례**
- 제철소는 철광석 분진과 붉은 도장, 안전 표지가 녹과 색이 비슷합니다.
- 이런 사진을 음성으로 따로 모아 학습에 넣습니다.

**탑재:** 320 입력에서 한 장에 약 15 ms(CPU 1코어 근사)입니다. 탑재 보드에서는 INT8 변환을 검토합니다([탑재 리소스](onboard-resources.md)).

## 2. 열화상 비전

**왜 원본 온도값을 쓰나**
- 색을 입힌 JPG는 이미지마다 색과 온도의 대응이 바뀝니다.
- 학습 입력은 픽셀마다 온도(℃)가 담긴 원본 열화상이어야 합니다. 합성 데이터는 16비트 PNG에 (온도 + 50) × 100으로 저장합니다.

**모델 구조**
1. 같은 배관의 축 방향 배경 온도를 구하고 그 차이(잔차)를 계산합니다. 배관마다 온도가 달라도 이상 부위의 모양은 비슷해집니다.
2. 겉보기 온도와 잔차를 2채널로 넣는 소형 분할 모델을 학습합니다. 기본 탐지기는 학습 없이 잔차에 임계값을 거는 방식입니다.
3. 스팀 트랩은 학습하지 않고 규칙으로 판정합니다. 트랩 위치는 설비 목록에 있으므로 입구·출구 온도를 비교합니다.

**합성 데이터에서 흔드는 조건**
- 외장 방사율: 알루미늄 약 0.05~0.3, 아연도 0.2~0.35, 스테인리스 0.1~0.3
- 반사: 위쪽은 하늘, 아래쪽은 지면
- 햇빛 가열, 바람, 센서 잡음, 고정 패턴 잡음
- 헷갈리는 비결함 사례: 반사 무늬, 외장 이음매, 차가운 지지대 클램프

**현장 운영 조건**
- 흐린 날이나 야간에, 바람이 약할 때, 배관과 외기 온도차가 클 때 찍습니다.
- 맑은 낮은 하늘 반사와 햇빛 때문에 성능이 떨어집니다. 이것이 합성 데이터의 `shifted` 조건입니다.
- 알루미늄 외장은 방사율이 낮아 온도차가 작게 보입니다. 외장 몇 곳에 방사율을 아는 테이프를 붙여 보정합니다.

**검증:** 열화상으로 찾은 젖은 구간은 보온재를 일부 열어 확인합니다. 열화상만으로 확정하지 않습니다.

## 3. 초음파 신호 분석 (기능 ②③)

| 작업 | 방식 | 학습 여부 |
|---|---|---|
| 두께 | 저면 에코 간격에 빗 모양 필터를 맞춰 계산하고 온도로 음속을 보정 | 학습 안 함. 물리식이라 설명이 쉽고 표준 측정 방식과 같음 |
| 균열 (사각 탐촉자) | 코너 반사가 와야 할 시간 창에서 잡음 대비 진폭으로 판정 | 지금은 규칙. 데이터가 생기면 1D-CNN 검토 |
| 내부 피팅 (수직 탐촉자) | 16회 평균, 정합 필터 특징, 소형 MLP, 적응 임계값(CFAR) | 학습함 |

**피팅 모델 학습**
- 일부러 넓게 흔든 합성 데이터로 학습합니다. 잡음 0.5~4배, 접촉 0.2~1.0, 온도 −10~220℃, 평균 횟수 1·4·16회입니다.
- 결함 없는 신호로 임계값을 맞춰 오경보율 0.5%를 목표로 합니다. 신호 세기 구간별로 따로 맞춥니다.
- 어려운 조건에서 피팅 검출률은 0.045에서 0.889로 올랐고 오경보는 0.7%입니다([결과](results.md)).

**실제 장비에 맞추는 순서**
1. 두께를 아는 계단형 블록으로 음속, 지연, 감쇠를 맞춥니다.
2. 바닥이 평평한 인공 구멍이나 홈을 판 블록으로 피트·균열 에코 진폭을 맞춥니다.
3. 맞춘 시뮬레이터로 다시 합성하고, 실측 수십~수백 개로 성능을 확인합니다.
4. 차이가 남으면 마지막 층만 실측으로 다시 학습합니다.

## 4. 실제 데이터가 생기면 필요한 양 (목표치)

| 모델 | 실측 데이터 | 양 (목표치) | 용도 |
|---|---|---|---|
| 녹 비전 | 배관 사진 + 마스크 | 100~300장 | 합성과 실사 차이 측정, 추가 학습 |
| 열화상 | 원본 열화상 + 보온재 개방 결과 | 젖은 구간 20~50곳 | 임계값과 POD 확인 |
| 초음파 | 보정 블록 파형 + 실제 배관 측정 파형 | 블록 2~3종, 실측 수백 점 | 시뮬레이터 보정, POD 확인 |

양은 이 정도면 차이를 잴 수 있다는 목표치이고, 근거가 있는 수치는 아닙니다.

## 5. 해커톤 당일 학습

- 녹 비전과 열화상 분할 모델은 GPU(Colab 또는 팀 GPU)에서 학습합니다. 방법은 [결과 문서](results.md)의 YOLO-seg 절에 있습니다.
- 초음파 모델은 CPU로 몇 분이면 학습됩니다.
- 이 저장소의 수치는 모두 학습 없는 기본 탐지기와 소형 모델 기준입니다. 학습한 모델의 수치는 아직 없습니다.
