# MAEK 자료 검토 기준

2026-11-09 사용자 지시: 매 조사에서 MAEK 목표와 정합성을 확인한 뒤 자료를 검토한다.

## 조사 전

1. 조사 질문을 “어떤 배관의 어떤 이상을 어떤 관측으로 찾고 어떤 후속 판단에 연결하는가”로 쓴다.
2. 최신 프로젝트 계획서 원문을 먼저 읽는다. 관측→진단→측정 품질→검사 후보→선정 근거 흐름과 연결한다.
3. MAEK는 가스 배관 전용이 아니다. 여러 매질·노출/보온 조건에서 외부 부식·누설, 내부 균열·피팅·
   두께 및 보온 이상을 다룬다. 냉각수·증기·열풍을 매질 이름만으로 배경/보조로 내리지 않는다.
4. 안전 우선·품질 불량 재검·동급 내 조업 영향/검사 소요 비교를 보여줄 사례를 선정한다.
   특정 계통을 중심으로 하는 검토는 해당 사례의 범위이며 전체 제품 범위로 일반화하지 않는다.

## 자료별 기록

| 항목 | 기록할 내용 |
|---|---|
| 조사 질문 | 해결하려는 MAEK 기능·입력·출력 |
| 출처 | 공식 URL, 발행 주체·일자, 페이지·그림·절 |
| 대상과 조건 | 매질·재질·보온 여부·온도·센서·검사 방식 |
| 확인된 사실 | 원문이 실제로 뒷받침하는 주장 |
| 목표 연결 | 관측·품질·위치·후속 검사·안전·조업 영향·예산 중 어떤 판단에 필요한지 |
| 관측 가능성 | RGB/IR로 보이는 단서와 UT/PEC 등 접촉 검사가 필요한 항목 |
| 한계 | 현장 검증 여부, 합성/실측 구분, 누락 조건, 데이터·재사용 권한 |
| 채택 판단 | 직접 적용 / 공정·환경 배경 / 별도 검증 필요 / 범위 밖 |
| 적용 제안 | 구현할 항목과 추가 검증. 확정된 사실과 구분 |

## 기존 고로 자료의 적용 해석

- 고로가스·냉각수·열풍·증기 자료 모두 대상 배관의 손상과 관측 가능성, 후속 검사 및 공정 영향에
  따라 직접 적용 / 공정·환경 배경 / 별도 검증 필요 / 범위 밖으로 판단한다.
- 냉각수 계통도는 공급/회수·비상 공급과 공정 영향 모델에 직접 활용할 수 있다. 배관 부식/감육의
  센서 검증 근거는 별도다. 가스 배관이 아니라는 이유로 검사 대상에서 제외하지 않는다.
- 고로가스 자료는 해당 매질·공정 조건의 사례이며 MAEK 전체가 가스관 중심이라는 근거가 아니다.
- 증기·보온 자료는 보온 배관 검사 기능과 연결되는 주요 후보가 될 수 있다. 이를 특정 가스 누출
  또는 균열 확정 성능으로 전환하지 않는다.
- 열풍·냉각관도 센서·재질·온도·접근 조건을 확인해 검사 대상으로 검토한다. 내화물이나 노내 설비
  손상은 외부 배관 영상 검사로 입증할 수 있다는 주장과 구분한다.
- 이전에 기록한 “가스 배관 중심 유지” 및 다른 계통을 일률적으로 보조로 취급한 방침은 철회한다.
