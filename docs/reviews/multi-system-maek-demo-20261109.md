# 프로젝트 계획서 기준 다계통 MAEK 시연 재검토

검토일: 2026-11-09. 최신 Google Docs 계획서 원문을 먼저 확인하고, Unity 소스·배관 목록·
촬영 계획 및 기존 Windows EXE 실행 증거를 대조했다. 장면·경로·분석·배포 EXE는 변경하지 않았다.

## 1. 제품 목표와 검토 결론

MAEK는 배관 영상·초음파 신호 등에서 이상을 찾고 점검 담당자에게 어느 배관을 먼저 어떤
방법으로 확인할지 제안하는 시스템이다. 가스 전용이 아니며 기본 가상망은 9종 매질·10종 결함이다.
이 수치는 현재 Unity의 14개 용도 서비스와 1:1 대응하지 않는다. 서비스 코드 수가 매질 수나
검증된 결함 종류 수를 뜻하지 않는다.

계획서 핵심 기능: RGB 외부 부식·누설, UT 내부 균열, UT 두께·피팅, IR/PEC 보온 배관,
안전·조업 영향 기반 검사 순위, 안전·생산·정확성 대시보드.
완료 기준은 한 구간의 관측→진단→측정 품질→검사 후보→선정 근거 추적이다.
계통마다 어떤 손상을 어떤 센서로 확인할 수 있는지 검증해야 하며 모든 매질에서 모든 기능이
동일하게 성립한다고 가정하지 않는다. 조업 영향도는 진단 모델 입력과 분리된 의사결정 입력이다.

계획서: https://docs.google.com/document/d/1FfAsoZOnLjI0hc3uvzqAkWLmLkO8IS1IBK8JXm9SqAg

## 2. 현재 구현과 증거

- 냉각수 공급/회수 102개, BFG 26개, 냉풍/열풍/연소공기/배기 98개,
  세정수/슬러리 10개, 훈련수 4개, 독립 질소/계장공기 7개로 합계 247개다.
- 기존 Windows EXE 실행 기록은 247개 배관·771장 촬영/분석, 39개 위치 표식,
  이동 충돌 검사 20,828단계를 통과했다. 이는 현장 정확도나 247개 배관 표면 전면 검사의 증거가 아니다.
- RGB 결과가 찍힌 위치에는 냉각수 BF1-W002/W003, BFG BF1-G004/G200,
  슬러리 BF1-Q003 등 여러 계통이 포함된다. 색상 기반 오탐 가능성 때문에 실제 부식 정답으로 취급하지 않는다.
- 실제 연결 분석은 HSV RGB 부식 후보 기준선이다. YOLO, UT, IR, PEC 실측, 안전·조업 영향·
  예산 순위 및 Streamlit 통합은 현재 EXE에 연결 완료되지 않았다.
- 촬영 가시성·이미지 해시·표면 위치·구간별 결과 기록은 있지만 일반적인 촬영 품질,
  상세 용접/엘보 특징점, 확정 재질/두께/보온 조건, 대체 공급 가용 용량이 충분히 연결되지 않았다.
- Python의 관측 품질/후속 검사 계획 모듈은 재사용 후보이지 Unity 연결 완료의 증거가 아니다.
- 현행 138개 주요 검사 필터와 98개 공정 설명 분류는 발표 편집 기준이다. 후자의 검사 가능성을
  배제하거나 전자를 현장 위험 순위로 취급하지 않는다.

## 4. 여러 계통의 대표 사례 제안

아래 사례는 적용 시나리오 제안이다. 실제 결함·안전 등급이 확인됐다는 뜻이 아니다.

### M01. 냉각수 공급·회수 — 외면 부식 후보→후속 두께 확인

- 대상: BF1-W002, BF1-W003
- 준비 상태: RGB 연결 활용 가능; UT 결과 연결 필요
- 보여줄 판단: 부식 후보 위치·촬영 근거·검사 접근 조건을 확인하고 두께검사 후보로 저장

### M02. 냉각수 또는 가스관의 용접 구간 — UT 균열 의심→안전 우선 검토

- 대상: BF1-W002
- 준비 상태: 관측 구간·용접 특징점·UT 파형/결과 연결 필요
- 보여줄 판단: 명시적 모의 UT 또는 실제 모듈 출력과 품질을 근거로 담당자 우선 검토; RGB 녹을 균열로 바꾸지 않음
- UT 합성 파형과 결함 정답을 분리한다. 모의 파형 입력이어도 실제 UT 모듈이 추론한 결과를 표시하고, 드론 RGB로 균열을 발견했다고 연출하지 않는다.

### M03. 고로가스 — 표면 후보·UT 감육/피팅·공급처 영향

- 대상: BF1-G004, BF1-G201, BF1-G110
- 준비 상태: RGB·계통 활용 가능; UT/공정 영향/예산 연결 필요
- 보여줄 판단: 정제 공정·열풍로·보일러 사용처를 구분하고 같은 안전 등급에서 대체 공급과 검사 소요 비교

### M04. 세정수 — 흐림·역광·가림→재촬영

- 대상: BF1-Q002
- 준비 상태: 형상·촬영 활용 가능; 품질 평가 연결 필요
- 보여줄 판단: 실제 촬영 열화 조건으로 품질 보류를 발생시키고 미검출을 정상 처리하지 않음

### M05. 슬러리 — 곡관 구간의 감육·피팅 확인

- 대상: BF1-Q003
- 준비 상태: RGB 활용 가능; 곡관 특징점·UT 두께 연결 필요
- 보여줄 판단: 국부 두께 근거와 재검 조건을 표시; 주황색 슬러지 얼룩은 부식 오탐 대조군으로 활용
- 현재 표면 색 검출을 내부 침식 확정으로 표시하지 않는다. 곡관 내부 두께는 접촉 UT 또는 명시적 합성 UT 근거를 사용한다.

### M06. 열풍 — 외피·보온 손상과 열적 이상

- 대상: BF1-H200
- 준비 상태: 기존 계통 활용; 실제 보온 구조 확인 및 IR 관측 생성/판독 연결 필요
- 보여줄 판단: 표면 온도 이상을 내화물·내부 균열 확정과 구분; 고온 접근·센서 조건에 맞춰 후속 검사 검토
- 현재 Unity에는 열화상 온도 관측이 없다. 단순 색상 필터를 열화상으로 소개하지 않는다. 고온 조건에 맞는 검사 적용성·접근을 확인하고 무조건 UT/PEC를 권하지 않는다.

### M07. 증기·응축수 — 보온 손상·습윤·트랩 점검과 조건부 PEC

- 대상: 증기 공급→보온 배관→사용처/트랩→응축수 회수의 신규 연결 회로
- 준비 상태: 계통·보온 구조·센서 입력 신규 추가 필요
- 보여줄 판단: 보온 이상 후보→재질/온도/보온 조건 확인→적용 가능한 PEC 평균 감육 선별→필요한 UT 확인; 열화상만으로 트랩 고장 확정 금지
- 신규 ID/유체 경로/공급·회수/보온 형상/Collider를 함께 추가해야 한다. 기존 247개 기준을 덮어쓰지 않고 확장 데이터·경로로 별도 검증한다. 일반 IR로 BFG 누설 검출을 대체하지 않는다.

### M08. 질소·계장공기 독립 시험대 — 닫힘·대기·미측정·결함을 구분

- 대상: UTIL-N002, UTIL-I003
- 준비 상태: 기존 시험대 활용; 상태 의미/품질/필수검사 화면 보완
- 보여줄 판단: 유량 0 또는 RGB 무검출이어도 건전·무압으로 처리하지 않음; 실제 고로 공급망과 구분
- 시험대의 독립성이 화면에 표시돼야 한다. 실제 누설을 보여주려면 매질에 맞는 별도 검출 근거가 필요하며 밸브 상태·시각 효과만으로 누설 판정을 만들지 않는다.

### M09. 여러 계통 공통 비교 — 안전 우선·재검·조업 영향·예산·계획 정비

- 대상: BF1-W002, BF1-Q002, BF1-G201
- 준비 상태: 모듈 공통 결과 계약·의사결정·대시보드 연결 필요
- 보여줄 판단: 필수/안전 검사 보존, 품질 불량 재검, 같은 안전 등급 내 영향/소요 비교, 예산 밖 후보와 담당자 검토 표시

## 5. 계획서 A/B/C를 만족하는 최소 시연 묶음

대표 계통을 많이 만드는 것과 판단 사례를 완성하는 것은 다르다. 최소 발표 흐름은 다음으로 제안한다.

- A: 냉각수 배관의 명시적 합성 UT 균열 의심→품질 확인→안전 우선 검토.
- B: 세정수 배관의 흐린 RGB 영상→판정 보류→재촬영/추가 검사.
- C: 고로가스 공급 분기의 관측→같은 안전 등급 후보 사이에서 공정 영향·대체 공급/검사 소요 비교.

이 매핑은 가상 시나리오 선택이며 냉각수는 항상 안전 1순위, 세정수는 중요하지 않음,
고로가스에는 우회가 없음이라는 일반 규칙을 만들지 않는다. 같은 안전 등급 비교를 위해
별도 후보의 동등 조건과 가정 장부를 표시한다. A는 위험 검토를, B는 재검을 보존하며
C의 조업 영향 점수가 안전 검토를 뒤로 미루지 못하게 한다.
확장 시연은 슬러리 감육과 증기 보온/PEC를 추가해 계획서의 기능 범위를 넓힌다.

## 6. 공통 보완 우선순위

### P0: 형상 확대보다 먼저 연결할 것

1. 공통 자산 계약: pipe_id/segment_id/feature_id, 매질, 재질·온도·보온 조건,
   연결 공정, 필수 검사/안전 등급, 대체 공급 가용성·용량, 검사 시간·비용·정비 검토 시간대.
   미확정 값은 unknown이며 가상 조건의 출처를 명시한다.
2. 공통 관측 계약: 센서/모델 버전/시각/품질/위치/증거 ID/원본 해시/진단 결과,
   synthetic 또는 measured 여부를 표시한다. 정답은 추론·순위 입력과 분리한다.
3. 모달리티 연결: RGB→IR→UT/PEC를 모두 수행했다고 가정하지 않는다. 실제 실행/모의 입력/
   미실행을 구분하고 진단값이 없으면 null로 유지한다. UT/PEC 접근은 드론 자유 촬영과 구분한다.
4. 품질·누락 상태: 가림, 흐림, 역광, 저해상도, IR 반사/정합 문제, UT 접촉 품질을
   센서별로 확인한다. 미검출/가림/서버 오류/미측정은 서로 다른 상태다.
5. 검사 후보 판단: 안전/필수 검사→품질 보류 재검→같은 안전 등급 내 공정 영향·소요 비교.
   예산 밖 필수 검사도 숨기지 않고 자원 부족을 표시한다. 운전 승인·정비 유예를 자동 결정하지 않는다.
6. 통합 결과 화면: 배관 번호 / 의심 이상 / 권장 검사 / 먼저 확인할 이유 / 정비 검토 시간대,
   관측 이미지·UT 파형·품질·선정 근거를 클릭으로 연결한다.

### P1: 대표 기능을 확인한 뒤 확대

- 기존 배관의 엘보·용접·플랜지·지지부 특징점 ID와 검사 시야를 보강한다.
- 보온 배관·증기/응축수·스팀트랩 계통은 물리적 연결과 검사 조건을 정한 뒤 추가한다.
- 기존 247개 전체 경로는 회귀 검증용으로 보존하고 A/B/C를 묶는 별도 짧은 경로는
  모든 이동 swept-sphere, 촬영 대상 가시성, 분석 순서와 근거 연결을 새로 검증한다.
- 계통 간 필터는 특정 매질을 제품 전체 목표로 고정하지 않고 기능/품질/위험/공정별로 전환한다.

### P2: 평가와 후속 현장 보정

동일 배관망·결함·예산·시드로 고정점/안전/안전+조업 전략을 비교한다. 위험 결함 누락,
조업 영향도 가중 발견률, 오경보, 두께 오차, 후속 검사당 발견 수를 분리한다. 독립 평가셋과
Jetson 실제 보드 측정을 사용하고 가상 전략 성과를 실제 중단 감소·생산량 증가로 발표하지 않는다.
현장 P&ID·재질·두께·온도·센서 적합성을 확보하기 전에는 현장 적용 완료로 표시하지 않는다.

## 7. 사례별 검증 기준

- 후보가 단일 배관/구간/특징점과 실제 관측 근거에 연결되는가?
- 색상 얼룩/정상 도장, 무검출, 흐림, 가림, 서버 장애, 폐쇄/대기 구간도 검증했는가?
- 각 센서의 모의·실측·미실행이 명확하며 정답이 검출기/순위로 들어가지 않는가?
- 동일한 위험 수준에서만 공정 영향 비교를 수행하고 필수/안전 검사를 보존하는가?
- 예산 초과·대체 공급 미확인·모든 관측 미확인 상태도 결과표에 남는가?
- 변경한 배관 그래프, 실제 형상, 충돌, 촬영과 저장 결과를 함께 확인했는가?

이번 문서의 기존 ID는 모두 247개 목록과 촬영 계획에 존재함을 검사했다.
이는 새로운 사례의 센서/순위 기능 구현 완료나 새 Unity 하니스 통과를 뜻하지 않는다.
