# 균열·피팅 최종 결과와 확인 범위

담당: 박성훈. 2026-11-09. 수치는 결함이 있는 가상 검사 지점 중 탐지한 비율(Recall)과 정상 지점 중 잘못 경보한 비율(FAR)입니다. 현장 성능·정확도·배관망 전체 발견율과 구분합니다.

## 균열: 정합필터 + CA-CFAR + MLP

32개 특징, 32·16개 은닉 노드, 출력 1개, 파라미터 1,601개입니다. 신호 세기·퍼짐·위치·CFAR 비율과 관측 가능한 공칭 정보·온도를 사용합니다. 실제 결함 깊이나 생성기의 정답 각도는 입력하지 않습니다. 최종 경보는 품질 조건·CFAR와 각도별 MLP 문턱값을 함께 통과해야 합니다.

학습 4,800개, 검증 1,200개, 정상 보정 12,000개를 사용했습니다. 모델과 문턱값을 고정한 후 새 시드의 9,600개 파형으로 평가했습니다. 16회 평균과 1회 측정은 같은 조건으로 취급하지 않습니다.

| 조건 | 균열 탐지 / 결함 수 | 탐지률 | 오경보 / 정상 수 | FAR |
|---|---:|---:|---:|---:|
| 일반 | 1,200 / 1,200 | 100% | 3 / 1,200 | 0.25% |
| 기본 악조건 | 1,195 / 1,200 | 99.583% | 0 / 1,200 | 0% |
| 두께·각도·지연 오차 | 1,194 / 1,200 | 99.50% | 0 / 1,200 | 0% |
| 온도·굴절각·형상 오차 | 1,191 / 1,200 | 99.25% | 1 / 1,200 | 0.083% |

출처: `crack_mlp/run/results.json`, `fresh_*_predictions.csv`, `audit.json`. 이전 감사에서는 9,600개 원시 파형으로 특징·판정을 재생했고 판정이 일치했습니다. 이 PR의 작은 예제 검증은 이전 전체 감사와 별도입니다.

기본 악조건 POD a90 약 0.265 mm, 온도·형상 오차에서 약 0.373 mm입니다. 미탐이 적은 합성 크기별 회귀의 참고값이며 깊이 추정 오차나 공인 POD 인증이 아닙니다. 일반 조건은 전부 탐지되어 유한 a90을 적합하지 않았습니다.

일반 100%, 기본 악조건 91.2% 이상, FAR 1% 이하라는 개발 목표를 **이번 합성 평가의 관측값**에서 만족했습니다. 모든 각도·재질·미지 조건의 보장은 아닙니다. 0/1,200 오경보의 양측 95% 신뢰구간 상한은 약 0.307%입니다. 오경보 4개는 모두 45도에서 발생했습니다.

## 피팅: MLP와 추가 노트북을 구분

### 보관된 피팅 MLP

수직 UT 16회 평균, 보정·신호처리와 작은 MLP 3개 앙상블 D를 사용한 결과입니다.

| 문턱값 선택 기준 | 일반 탐지 / 정상 오경보 | shifted 탐지 | shifted 오경보 |
|---|---|---|---|
| 보정 목표 FAR 0.7% | 2,000/2,000, 5/2,000 | 1,751/2,000 = 87.55% | 12/2,000 = 0.60% |
| 보정 목표 FAR 1% | 별도 운영점 | 1,784/2,000 = 89.20% | 17/2,000 = 0.85% |

출처: `reports/pitting_final_results.json`의 `D_new_MLP_no_hard_gate`, `n_avg=16` 행. 보정 목표와 최종 관측 FAR는 다릅니다. 피팅 MLP는 탐지률 88.9% 이상과 FAR 0.7% 이하를 동시에 달성하지 못했습니다.

### UT.ipynb의 피팅 1D-CNN

입력 RF 4,096개 표본, 학습 데이터 공통 정규화, 파라미터 145,281개입니다. 악조건 재학습과 정상 보정으로 저오경보 운영점을 정한 별도 피팅 실험입니다. 균열 MLP와 모델 우열을 비교하지 않습니다.

| 조건 | 저장 출력 탐지률 | 탐지 수* | 오경보 / 정상 수 |
|---|---:|---:|---:|
| 일반 | 98.775% | 3,951 / 4,000 | 0 / 4,000 |
| shifted | 95.475% | 3,819 / 4,000 | 2 / 4,000 = 0.05% |

*탐지 수는 노트북에 저장된 정밀 탐지률과 분모 4,000으로 환산했습니다. 개별 판정 CSV에서 독립 재집계한 수가 아닙니다. 출처는 `notebooks/UT.ipynb`의 0부터 센 19번 셀이며 기계 판독용으로 `reports/pit_notebook_saved_results.json`에 기록했습니다.

저장 출력은 피팅 개발 목표의 관측값을 충족합니다. 최신 가중치·전처리 설정·외부 실행 스크립트·최종 파형이 추가 자료에 없어 현재 패키지에서 재생 검증을 완료했다고 말하지 않습니다. Colab T4 배치 평균 지연을 Jetson 단건 지연으로 바꾸어 인용하지 않습니다.

## 추가 데이터와 남은 범위

`datasets/registry.json`의 자료는 이전 균열 v3·스트레스 시험, 피팅 MLP v2, 실측 노치 크기 추정 결과, 공개 NDT 후보입니다. 공개 실측 후보를 받았다는 사실만으로 최신 MLP가 실측 학습·평가를 마쳤다고 표시하지 않습니다.

사각빔 균열과 수직 UT 피팅은 서로 다른 입력 모형입니다. 수직 피팅 결과를 70도 사각빔 피팅 성능으로 옮기지 않습니다. 미지 재질·곡률·웨지 내부 가열·전체 탄성파 경계 산란과 Jetson 속도는 이번 패키지에서 추가 검증하지 않았습니다. 기존 두께 결과 역시 주벽 두께와 피팅 바닥 최소 잔여 두께를 구분해야 합니다.
