# MAEK 배관·제선 공정 적합성 검토 — 2026-11-09

## 결론

현재 환경은 **고로 제선 구역을 배경으로 한 RGB 부식 후보 선별 시연에 조건부 적합**하다.
247개를 모두 동일한 중요도의 실제 공정 검사 배관으로 설명하거나, 압력·유량·CFD 결과를
포스코 실제 운전 재현으로 설명하는 것은 부적합하다. 충돌 검사 통과와 공정 설계 타당성은 별개다.
이번 검토는 저장된 배관 목록·연결 그래프·계산 결과·구현 코드를 대조한 것으로,
현장 P&ID 인증이나 새 Unity Play/충돌 검사 실행은 아니다. 장면과 기존 비행 경로는 수정하지 않았다.

## 고로가 담당하는 공정

고로는 제선 설비다. 소결광·펠릿·괴광과 코크스 등을 상부에 장입하고, 하부 풍구에서
열풍을 공급하여 철광석을 환원·용융한다. 생성된 용선은 주상 출선구와 내화물 유로를 거쳐
운반되어 다음 제강 공정으로 간다. 슬래그는 별도 처리되고 노정 가스는 집진·정제 후 연료로 회수된다.
고로 주변을 제강 전로, 연주기 또는 압연 라인으로 소개하면 안 된다.

합계 247개: 우선 검사 후보 138개, 공정 맥락 98개, 훈련 4개, 독립 유틸리티 7개.
이는 **시연 편집용 역할 분류**이며 현장 위험도 순위·검사 적합성 인증이 아니다.
고온·보온 배관도 외관 검사가 가능하므로 배제 대상이라고 단정하지 않는다.
보온 외피의 RGB 표식과 내부 모재 부식·내화물 열화를 구분해야 한다.

고로별 ST1은 ON_BLAST, ST2/ST3는 ON_GAS이며 냉·열풍 분기와 가스·연소공기·배기 분기가
반대 상태로 격리되어 있다. 기본 정적 상태는 일관적이나 실제 절환 시퀀스·인터록 검증은 별도다.

## 반드시 바로잡아야 할 설명과 부족한 부분

1. **압력·유량은 가정값**: config의 송풍기 압력 상승은 3,000 Pa다. 기준 BF1-H200은
   103,289.184 Pa(abs), 즉 대기압 101,325 Pa 대비 약 1.964 kPa(g), 6.625 kg/s다.
   BF1 노정도 약 102,128.736 Pa(abs)다. POSCO 공개 설명의 열풍 약 4.0 bar와 비교하더라도
   같은 운전규모를 재현했다고 할 수 없다. 공개 설명은 압력 기준이 명확한 설계 사양서가 아니므로
   그 수치를 단순 복사해 보정해서도 안 된다. 현재 1473 K 열풍 온도 가정만으로 실규모 검증이 되지 않는다.
2. **치수·유체 모델의 단순화**: 모든 배관의 내경/외경 비를 0.9로 두고, 손실계수를 공통 적용한다.
   실제 배관 스케줄, 재질, 내화물, 밸브 종류와 운전 자료를 반영한 설계 계산은 아니다.
   BFG도 등가 분자량을 사용하는 근사다. 냉각수 공급·회수 온도를 모두 303 K로 두어
   실제 열수지와 온도 이상 진단을 검증하는 데 부족하다.
3. **질소 사용처 미연결**: 정상 baseline에서는 UTIL-N002와 밸브 내부 통로가 닫혀 있다.
   질소가 흐르지 않는 것을 단선으로 판정하면 안 된다. utility_test는 시험대 개방 시나리오이며
   고로 실링/퍼지 계통 전체 구현이 아니다. 실제 부하·조절/차단·안전 배출 조건을 정한 뒤 확장해야 한다.
4. **고로 보조 계통의 범위 한계**: catalogue에 별도 산소 부화·PCI 분탄 이송 서비스가 없다.
   산소·분탄 사용을 표현하려면 공급원→조절·분배→풍구 주입 지점을 추가 정의해야 한다.
   풍구별 냉각 회로, 장입부 실링/퍼지, 주상 집진 등 상세 설계도 현재 247개만으로 입증되지 않는다.
   이들을 모두 만들 필요는 없지만, 구현 완료된 고로 전체 계통이라고 소개하면 안 된다.
5. **CFD 해상도·매핑**: 고로당 12개 풍구를 8개 shaft sector로 묶는다
   (`sector = int(round(k*8/12)) % 8`). 이는 문서화된 축약이며 12개 풍구 일대일 CFD가 아니다.
   shaft는 정상상태 양방향, hearth는 일방향 경계 연계다. 실제 전체 고로 다상 운전 검증과 구별한다.
6. **MAEK 연결 범위**: 현재 시연은 `segment_rust` HSV RGB 규칙 검출이다.
   열화상·UT·PEC 실측과 위험 기반 검사 우선순위 최적화는 이 시연 경로에 연결되어 있지 않다.
   부식색 후보가 검출되지 않아도 보온재 내부, 두께, 균열 건전성을 판단할 수 없다.
   전체 247개 촬영은 표면 전면 검사 완료를 뜻하지 않는다.
7. **장식과 검사 대상을 구분**: 외관 보강용 닫힌 보조 회로와 정비동 냉간 스풀 12개는
   공정 catalogue 밖의 모형이다. 실제 공급·소비 부하가 있는 배관으로 설명하거나 MAEK 검사
   완료율의 분모에 넣으면 안 된다. 주상 용선은 보통 내화물 유로로 표현하고 일반 냉각수관과 혼동하지 않는다.

## MAEK 시연에서 줄일 내용

- 기본 영상에서는 독립 질소·계장공기 시험대와 주상 훈련 루프를 별도 교육 장면으로 돌린다.
  기존 전체 247개 경로는 유지하되, 발표용 발췌 영상은 검사 의미가 뚜렷한 구간을 선택한다.
- CFD 단면·용선 반응은 짧은 공정 설명용 선택 화면으로 둔다. RGB 부식 선별 성능의 증거가 아니다.
- 정비동 작업대·공구함·장식 배관·넓은 건물 내부의 긴 순회는 주 시연에서 줄인다.
  배경·충돌체로는 남길 수 있으며 삭제할 필요는 없다.
- 환상관의 반복 구간을 전부 같은 비중으로 보여주기보다 냉각수 공급관 BF1-W002,
  회수관 BF1-W003, 세정수 BF1-Q002, 슬러리 BF1-Q003 및 가스 계통의 위치를 연결해 보여준다.
  현재 검출 결과가 확인된 구간을 사용하고 검출을 강제하거나 예상 결함을 분석기에 넣지 않는다.

권장 흐름: 제선 전경→대상 계통·유체·배관 ID 설명→드론 RGB 촬영→배관 위치에 부식 후보 표식→
후속 UT/PEC 필요 안내. 위험 기반 검사 우선순위까지 소개하려면 실제 MAEK 순위 산정 모듈의
입출력과 이 배관 ID를 추가 연결하고 별도로 검증해야 한다.

## 이번 자동 확인 결과와 한계

`scripts/audit_process_suitability.py` 실행 결과:
- 배관 ID 247개 고유, catalogue와 network 및 수리 시나리오 3개의 ID 집합 일치.
- 외부 배관 양 끝 좌표와 노드 좌표 오차 ≤0.001 m, 매체 및 service 분류 일치.
- 활성 내부 통로와 닫히지 않은 배관을 사용한 요구 경로 62/62 연결.
- **구조 검사 PASS, 공정·MAEK 완성도는 조건부 적합**.

연결 검사는 양방향 그래프다. 노드의 from/to는 저장 방향이며 환상관의 실제 유동 방향은
부호 있는 계산 결과를 따라야 한다. 닫힌 밸브는 제외하며 standby 표기는 토폴로지상 가용성을
뜻할 뿐 실제 유량이 있다는 판정이 아니다. 이 검사는 압력 방향 도달성, 형상 충돌, 지지 구조,
P&ID 안전 설계, 검사 접근 안전을 인증하지 않는다. 기존 Collider 검증은 이전 실행 증거로 유지한다.

산출물: `visualization/process_suitability/audit.json` (입력 SHA-256 포함),
`visualization/process_suitability/pipe_roles.csv` (247개 역할·상태·노드), 본 문서.

재실행: `.venv/Scripts/python.exe scripts/audit_process_suitability.py`.
