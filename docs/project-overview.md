# MAEK (맥) 프로젝트 설명서

**파이프의 맥을 읽는다.** POSCO AI Hackathon 2026 안전 주제 출품작입니다.

> 드론의 카메라·열화상으로 낡은 배관의 이상을 먼저 찾고, 의심 지점만 초음파·PEC로 재서, 같은 점검 비용으로 위험 결함을 약 3배 더 찾습니다.

모든 수치는 가상 배관망 시뮬레이션에서 나온 값입니다. 실제 포스코 현장 데이터로 검증하지 않았습니다.

## 1. 문제

**배관 사고는 사람을 다치게 합니다.**
- 2018~2026년 포항·광양제철소에서 보도된 안전사고는 22건이고, 사망자는 20명입니다. 사망자 중 16명은 협력·하청·용역 노동자입니다([사고 아카이브](posco-safety-accidents.md)).
- 이 중 가스 누출·질식·폭발처럼 배관과 관련된 사고가 많습니다. 예로 2025년 11월 포항 STS 4제강 가스 사고, 같은 달 소둔산세공장 유해물질 누출이 있습니다.
- 일산화탄소(CO)가 든 부생가스, 산소, 불산 배관은 핀홀 하나도 치명적입니다.

**지금의 점검 방식은 느리고, 가장 위험한 곳을 놓칩니다.**
- 수백 km 배관을 사람이 걸어서 보고, 정해진 고정 측정점에서 초음파로 두께를 잽니다.
- 고정점은 직관부 중앙에 있어 감육이 몰리는 엘보나 용접부를 거의 보지 못합니다. 측정의 99%는 결함이 없는 자리를 잽니다.
- 높은 곳 배관은 비계를 세워야 합니다. 비용의 약 80%가 비계이고, 높은 곳 작업은 추락 위험이 큽니다.
- 보온 배관은 보온재를 뜯어야 속을 볼 수 있습니다. 보온재 밑 부식(CUI)은 겉에서 거의 안 보입니다.

## 2. 해결 방법

**핵심 기능 3가지**

| 기능 | 장비 | 찾는 것 |
|---|---|---|
| ① 부식 탐지 | 카메라 (드론, 로봇, CCTV) + AI 분할 모델 | 외부 녹, 보온 외장 얼룩·파손, 누설 흔적 |
| ② 내부 균열 탐지 | 초음파 사각 탐촉자 + 신호 판정 | 겉에서 안 보이는 균열 |
| ③ 두께 측정 | 초음파 수직 탐촉자 + 신호 처리·소형 학습 모델 | 감육, 내부 피팅, 남은 수명 |

**보온 배관용 보조 장비 2가지** (증기·응축수·트레이싱 배관)

| 장비 | 찾는 것 |
|---|---|
| 열화상 + AI | 젖은 보온재, 보온 손상, 증기 누설, 스팀 트랩 이상 |
| PEC (펄스 와전류) | 보온재를 뜯지 않고 평균 두께 측정 |

**점검 흐름**
1. **넓게 봅니다.** 드론이 전 구간을 일반 카메라와 열화상으로 찍고, AI가 이상 위치를 표시합니다.
2. **골라서 잽니다.** 다음 위치만 측정합니다.
   - AI가 표시한 곳
   - 감육·균열이 몰리는 위험 지점: 엘보, 용접부, 지지대, 저점
   - 보온 배관은 PEC로 먼저 재고, 이상이 보이는 곳만 보온재를 열어 초음파로 확인합니다.
3. **순서를 정합니다.** 흐르는 물질의 피해 등급, 설치 연식, 사람 통행으로 위험도를 매겨 정비 우선순위를 냅니다.

## 3. 데이터가 없는 문제: 디지털 트윈 시뮬레이터

실제 점검 데이터는 받을 수 없어서, 가상 제철소 배관망을 만들고 센서를 소프트웨어로 흉내 냈습니다.

| 구성 | 내용 |
|---|---|
| 가상 배관망 | 100 km, 50 m 구간 2,000개. 매질 9종(냉각수, 증기, 응축수, 트레이싱, 부생가스, 산소, 질소, 산세액, 압축공기), 관경, 재질, 연식, 보온, 가공 여부 |
| 결함 주입 | 외부 부식, CUI, 유동가속부식 감육, 내부 피팅, 균열, 플랜지 누설, 보온 손상, 젖은 보온재, 증기·트레이서 누설, 트랩 고장. 발생 위치와 확률은 문헌 근거나 명시한 가정을 따름 |
| 카메라 | 2D 합성 렌더러. 이미지, 마스크, YOLO-seg 라벨 |
| 초음파 | 물리 기반 A-scan 파형(수직·사각 탐촉자), 잡음·접촉·온도 반영 |
| 열화상 | 열전달 + 방사율·반사 카메라 모델, 16비트 온도 이미지 |
| PEC | 보온 두께에 따른 풋프린트 평균, 잡음 |
| 에너지 | 증기 누설(Napier 식), 보온 손실, CO2 |
| 점검 전략 | 사람+비계 / 드론 / 드론+AI 세 방식을 같은 배관망에서 몬테카를로로 비교 |

- 모든 파라미터에 출처나 "가정" 표시가 있습니다([파라미터 표](params.md)).
- 학습에 쓰지 않은 어려운 조건(`shifted`: 잡음, 어두운 조명, 맑은 낮, 접촉 불량)을 따로 만들어 평가에만 씁니다.
- 만든 데이터는 초음파 13,000개, 카메라 2,400장, 열화상 1,300장, 전략 비교 결과입니다(GitHub `data-v3` 브랜치).

## 4. 결과

**기본망 100 km** (20회 평균, 괄호는 사람+비계 대비)

| 지표 | 사람+비계 | 드론 | 드론+AI |
|---|---|---|---|
| 위험 결함 발견율 | 0.19 | 0.27 | 0.59 |
| CUI | 0.23 | 0.34 | 0.68 |
| 유동가속부식 감육 | 0.03 | 0.02 | 0.62 |
| 놓친 고피해 위험 결함 | 39.6개 | 33.3개 | 19.5개 |
| 비계 설치·해체 시간 | 9,213시간 | 5,100시간 | 3,692시간 |
| 소요 일수 | 385일 | 299일 (×0.78) | 238일 (×0.62) |
| 비용 | 35.3억 | 24.7억 (×0.70) | 19.2억 (×0.54) |

**증기 계통 대표 시나리오 20 km**

| 지표 | 사람+비계 | 드론 | 드론+AI |
|---|---|---|---|
| 위험 결함 발견율 | 0.15 | 0.21 | 0.59 |
| 젖은 보온재 발견 | 0.10 | 0.55 | 0.81 |
| 비용 | 9.0억 | 8.7억 (×0.97) | 7.5억 (×0.83) |

**세 기능의 기본 성능** (학습 조건 / 어려운 조건)

| 기능 | 지표 | 값 |
|---|---|---|
| ① 부식 (규칙 기반 기준선) | 결함 단위 hit율 | 0.99 / 0.31 |
| ② 균열 | 검출률 | 1.00 / 0.91 |
| ③ 두께 | 두께 오차 | 0.002 mm / 0.02 mm |
| ③ 내부 피팅 | 검출률 (오경보) | 1.00 / 0.89 (0.7%) |

①은 해커톤 당일 YOLO-seg 학습으로 개선할 기준선입니다.

## 5. 왜 가치가 있나 (그리고 어디까지인가)

**단단한 근거**
- **발견율 약 3배.** 환경 가정을 15가지로 바꿔도 2.7~4.6배가 유지됩니다([가정 흔들기](robustness.md)).
- **놓친 고피해 결함이 절반으로.** CO·산소·불산 배관의 위험 결함 놓침이 40개에서 20개로 줄어듭니다.
- **높은 곳 작업 시간 60% 감소.** 비계 작업이 9,213시간에서 3,692시간으로 줄어듭니다. 추락 위험과 직결됩니다.
- **포스코에 실제 수요가 있습니다.** 광양제철소는 2026년부터 에너지 패트롤로 스팀 배관의 누설, 보온 상태, 고장 트랩을 점검하고 있습니다. 포항제철소는 2017년부터 열화상 드론을 쓰고 있습니다.

**솔직한 한계**
- **비용 절감은 높은 곳 접근 방식에 달려 있습니다.** 비계를 쓰면 약 절반이지만, 고소작업차로 효율적으로 오르면 비용이 비슷합니다(×1.02). 그래서 주장은 "싸다"보다 "같은 돈으로 더 많이 찾는다"입니다([비용 모델](cost-model.md)).
- **내부 피팅은 여전히 어렵습니다.** 겉에 징후가 없어 피트 하나하나의 발견율은 5% 수준입니다. 대신 일부 구간만 재서 회로 단위로 교체 여부를 판정하는 극치통계 방법을 제안합니다. 피팅이 넓게 퍼진 회로에서는 길이의 3%만 재도 교체 대상의 86%를 골라냅니다([피팅 전략](pitting-strategy.md)).
- **에너지 절감은 부수 효과입니다.** 증기 20 km의 연간 손실은 약 1.7억 원이지만, 기존 트랩 점검으로도 대부분 찾습니다.
- **모든 단가와 많은 확률은 가정값입니다.** 포스코의 실제 배관 길이와 구성도 모릅니다.

## 6. 포스코 현장에 붙이는 방법

| 포스코 데이터 | 바뀌는 것 |
|---|---|
| 설비관리 시스템의 배관 목록 | 가상 배관망 대신 실제 배관 |
| 두께 측정 기록, 결함·누설 이력 | 결함률 보정, 결과 검증 |
| 스팀 트랩 목록과 점검 결과 | 에너지 손실 계산 |
| 비계·보온 해체·외주 점검 단가 | 비용 비교 |
| 현장 사진·열화상·초음파 파형 소량 | AI 모델 보정 ([학습 전략](learning-strategy.md)) |

코드는 그대로 두고 설정만 바꿔 다시 계산합니다. 예: `python -m maek strategy --set strategy.cost_scaffold_krw=800000`

**단계별 도입안**
1. 한 공장의 증기 배관 1~2 km에서 열화상 드론과 PEC로 시범 점검하고, 보온재를 열어 결과를 확인합니다.
2. 확인 결과로 열화상·PEC POD와 단가를 보정하고 시뮬레이터를 다시 돌립니다.
3. 효과가 확인된 매질과 구역부터 넓힙니다. CO 가스 배관처럼 피해 등급이 높은 곳을 먼저 합니다.

## 7. 기술 구성

- Python(numpy, pandas), 설정 YAML 하나(`config/default.yaml`)와 시나리오 덮어쓰기(`config/scenarios/`)
- 명령: `python -m maek network | ut | camera-jobs | render2d | thermal | strategy | sweep | eva | evaluate | onboard`
- 탑재: 부식 분할 320 입력에서 약 15 ms, 초음파 판정 약 1 ms(개발 PC CPU 1코어 근사, [탑재 리소스](onboard-resources.md))
- 테스트 190개, GitHub Actions CI
- 저장소: https://github.com/nalziori/MAEK · 데이터: `data-v3` 브랜치 · 결과 요약: 구글 드라이브 MAEK 폴더
