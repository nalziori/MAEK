# MAEK 연결 배관 모델의 근거와 범위

이 모델은 공개 공정도에 근거한 **가상 제철소 배관 검사 환경**입니다.
포스코의 실제 P&ID·준공도·배관 아이소메트릭은 제공되지 않았습니다.
설비 연결 순서의 참고 근거와, 시각화를 위해 정한 공간 배치를 구분합니다.
사진은 고로·철골·컨베이어·건물 외형을 파악하는 용도로만 사용했습니다.

## 열어 볼 파일

- `maek_connected_steelworks.blend`: 연결을 다시 구성한 새 모델.
- `connected_overview.png`, `connected_furnace.png`: 전체와 고로 계통 전경.
- `connected_inspection.png`: BF1-W002 배관에 붙인 검사 구역.
- `connected_flow_overview.png`: 방향 화살표가 켜진 전체 계통.
- `connected_network.json`: 설비·접속점·배관·설비 내부 연결·운전 상태.
- `connected_line_list.csv`: 각 관의 출발점, 도착점, 유체, 가상 관경, 상태, 근거.
- `connectivity_report.json`: 검증 결과와 개별 경로.
- `process_flows.svg`: 직접 작성한 계통 개요. 원본 도면의 복제본이 아닙니다.

## 모델에서 정한 가정

- 두 고로 계통은 동일한 공개 공정 원리를 적용한 가상의 두 모듈입니다.
- 좌표, 고도, 관경, 고로 크기, 설비 간 거리와 배관 경로는 모두 시각화용 가정입니다.
- 열풍로 1은 송풍, 열풍로 2·3은 가열 상태입니다. 해당 분기관에 닫힘/열림 상태를 기록했습니다.
- 열풍과 연료 가스는 같은 배관망으로 합쳐지지 않습니다. 열풍로 내부 연결도 운전 상태별로 구분합니다.
- 냉각수는 고로의 가상 냉각 구역 12개를 지나 회수되어 공랭 냉각기와 펌프로 돌아옵니다.
- 열풍 환상관의 풍구 12개, 냉각수 분기 12개는 표현을 위한 축약입니다. 실제 설비 개수가 아닙니다.
- 가스 세정수는 냉각수와 별도 회로입니다. 보충수 탱크와 슬러지 수취부를 명시했습니다.
- 송풍기 흡입과 굴뚝 배출은 대기 경계입니다. 연결되지 않은 관의 임의 끝단이 아닙니다.
- 내부 복잡한 설비는 입출구를 가진 블랙박스로 표현합니다. 내부 세부 배관은 생략했습니다.
- 보일러는 연료 이용처와 배기 흐름만 표현하며, 증기 계통 전체는 모델링하지 않았습니다.
- 냉각 회로의 세부 형상·펌프·공랭기 배치는 가상 설계입니다.
- 이전의 검증되지 않은 장식용 배관은 새 파일의 `00_ARCHIVE__unverified_previous_geometry`에 보존하고
  렌더와 화면에서 숨겼습니다. 기존 .blend 파일은 수정하지 않았습니다.

## 연결과 검증

236개 배관 구간은 시작·끝 접속점 ID, 유체, 방향, 상태, 출처를 가집니다.
관의 3D 중심선은 JSON과 동일한 데이터에서 생성합니다.
T 분기는 접속점에서 본관을 나누며, 환상관도 분기마다 구간을 나눕니다.
서로 교차하는 별도 계통은 접속점으로 등록하지 않습니다.
파이프 표면은 곡선 객체이며, CFD용 단일 수밀 체적 메시나 제작용 CAD 형상은 아닙니다.

검사는 다음을 확인합니다.

1. 모든 관 양끝의 접속점 등록 및 좌표 일치.
2. 일반 설비 포트에 관 하나, 분기점에 관 둘 이상 연결.
3. 관 안에서 유체가 바뀌지 않음.
4. 요구한 60개 운전 경로 도달 가능.
5. 송풍 중인 열풍로의 연료 차단과 가열 중인 열풍로의 냉풍 차단.
6. 곡관을 반영한 중심선과 관 반지름 기준 관-관 의도치 않은 겹침.
7. Blender에 생성된 실제 관 객체의 양끝 좌표와 데이터 일치.

이 검증은 수치 유량·압력·온도·열응력·관벽 두께·지지대 하중·배수 구배·밸브 규격·
플랜트 설계 기준 적합성 또는 모든 구조물 간섭을 검증하지 않습니다.
우회관, 비상/정비 운전, 안전 계장, 모든 드레인·벤트를 포함한 완전한 P&ID도 아닙니다.
따라서 실제 시공·운전 도면이나 검증된 물리 시뮬레이터로 사용하면 안 됩니다.

## MAEK와 연결하는 지점

Blender 관 객체 이름과 `id` 속성이 CSV/JSON의 line_id와 같습니다.
예: `BF1-W002`는 냉각수 펌프에서 공급 환상관으로 이어지는 관이며,
검사대·UT 프로브와 예시 부식 표면은 이 관에 붙어 있습니다.
부식 표면은 합성 시연 표시이며 관을 끊거나 실제 결함 판독을 수행하지 않습니다.
MAEK 판독 UI나 AI 모델이 구현되었다는 뜻도 아닙니다.

카메라 01은 1–240프레임(24 fps)에서 전경 → BF1 → 검사대 순서로 접근합니다.
`06_Flow_arrows` 컬렉션을 켜면 연결 방향 표시를 볼 수 있습니다.
방향 화살표는 연결 해설이며 실제 속도·유량 결과가 아닙니다.

## 다시 생성

`connected_network.py`에서 설비 접속점과 배관을 수정하고,
`validate_connected_network.py`를 실행해 보고서를 확인합니다.
이후 Blender로 `build_connected_steelworks.py`를 실행합니다.
검사에 실패하면 모델 생성 전에 중단합니다.
