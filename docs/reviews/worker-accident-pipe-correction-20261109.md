# 사고 배관 확인과 Unity 수정

2026-11-09. 최신 계획서를 먼저 확인했다. MAEK는 여러 매질 배관의 이상 관측·진단과
검사 후보·선정 근거를 제공하며 작업 허가나 자동 운전 판단을 내리는 시스템이 아니다.

## 반영한 시뮬레이터 수정

- `Source/worker_safety_context.json`: 실제 보도 사례 4개와 현재 모델의 가상 검사 사례 3개를
  분리한다. 실제 사례의 `pipeIds`는 빈 배열이고 `modelStatus=not_modelled`로 유지한다.
- `MAEKWorkerSafety`: 14개 서비스의 매질·작업 위험 맥락·검사 한계·작업 허가 미판정 표시.
  실제 사고 계통을 다른 매질의 기존 가상 ID로 연결하면 검증이 실패한다.
- 공정 안내 패널에서 사고 배관 확인/계통 안내를 전환하고 이전/다음 사례를 볼 수 있다.
  원문 링크 버튼을 제공한다. 각 실제 사고에 현재 구현되지 않았음을 표시한다.
- 기본 결과표를 전체 247개로 전환한다. 138/98개 분류는 편집용 표시 그룹이며 위험 순위가 아니다.
- 후속 확인 목록에 `workerContext`, `inspectionLimit`, `workPermissionStatus=not_assessed`,
  `syntheticAsset=true`를 포함한다. 후보 없음·폐쇄·유량 0이 작업 안전 승인으로 변환되지 않는다.
- 결과 표식과 상태의 일률적 UT/PEC 권고를 후속 검사 적용성 검토로 수정했다.
  실제 후보의 recommendation은 해당 서비스 조건의 안내를 따르며 작업 허가 미판정임을 남긴다.
- 녹화 메타데이터에도 가상 배관·실제 사고 위치 아님·작업 허가 미판정을 기록한다.
- 기존 247개 형상·매체·연결·연속 경로는 유지한다. 산소/소결/산세/증기 신규 실물 회로와
  해당 사고의 물리적 재현을 추가한 것은 아니다. 새 회로는 별도 실제 자료와 안전·연결·충돌 검증이 필요하다.

## 검증

`tests/test_worker_safety_context.py`는 사고 4종의 잘못된 기존 ID 매핑,
작업 허가 승인, 매질 프로필 누락, 존재하지 않는 대상 ID를 거부한다.
기존 RGB·경로 테스트와 합계 19개 통과. 전체 Unity 장면 재빌드, Collider, 에디터/Play
촬영·분석 후 현재 실행 증거를 갱신하며 그 결과는 `visualization/worker_safety/verification.json`에 기록한다.
이전 배포 ZIP/EXE는 이 수정 전 버전이며 소스 수정만으로 해당 바이너리가 변경되지 않는다.
