# MAEK (맥)

**파이프의 맥을 읽는다.** POSCO AI Hackathon 2026(2026.11.09~11.10) 안전 주제 프로젝트입니다.

제철소의 낡은 배관·덕트에서 부식과 감육을 먼저 찾아내고, 사람이 정밀검사할 곳을 골라 주는 AI를 만듭니다.

## 문제

포항·광양제철소에서는 부식된 배관이 부서지거나(2020.12 포항 3소결), 노후 덕트가 무너지는(2025.07 광양 소결공장) 사고가 있었습니다.
포스코는 사람 점검, 드론·4족 로봇 순찰, 회전설비 예지정비를 쓰고 있지만, 공개 자료에서는 배관 열화를 AI로 판단하거나 위험도로 점검 순서를 정하는 시스템을 찾지 못했습니다.

## 구조

1. **영상 1차 선별:** 드론·로봇·CCTV 영상에서 부식, 보온재 손상, 누출 흔적을 찾습니다.
2. **의심 지점만 정밀검사:** 고른 곳만 초음파로 두께를 재고 남은 수명을 계산합니다.
3. **위험도로 순서 정하기:** 흐르는 물질(산소·불산·CO), 사람 통행, 연식으로 점검 순서와 작업지시서를 만듭니다.

밸브 격리 실패나 작업 중 가스 발생처럼 비파괴검사로 막을 수 없는 사고는 범위 밖으로 둡니다.

## 데이터

실제 점검 데이터가 없으므로 100km 규모의 가상 배관망에 결함을 현실적인 확률로 넣고, 카메라와 초음파 센서를 소프트웨어로 흉내 내 데이터를 만듭니다.
같은 시뮬레이터로 학습·평가하는 함정을 피하려고 학습에 없던 조건 테스트, 실제 부식 사진 검증, 탐지 확률(POD) 곡선으로 평가합니다.
