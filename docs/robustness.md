# 포스코 환경을 모를 때: 가정을 흔들어 본 결과

포스코가 어떤 배관을 몇 km 운용하는지, 보온·연식·결함률이 어떤지는 공개되어 있지 않습니다. 그래서 세 가지로 대응합니다.

1. **총액 대신 km당 값과 비율로 말합니다.** 총 길이가 달라도 방식 간 비교는 유지됩니다.
2. **환경 가정을 넓게 바꿔 결론이 유지되는지 봅니다.** 아래 표입니다.
3. **포스코 데이터가 들어오면 바꿀 입력을 정해 둡니다.** 맨 아래 표입니다.

## 가정을 바꿔 본 결과

`python -m maek sweep --runs 5 --total-km 20 --seed 1` (기본망 구성 20 km, 5회 평균; 데이터의 `strategy/sweep.csv`)

| 바꾼 가정 | 위험 결함 발견율 (사람+비계 / 드론+AI) | 발견율 배수 | 드론+AI 비용 비율 | 드론+AI 소요 일수 비율 | 에너지 손실 발견 (사람+비계 / 드론+AI) | 드론+AI가 더 많이 찾고 더 쌈 |
|---|---|---|---|---|---|---|
| 기본 | 0.15 / 0.51 | 3.5 | 0.54 | 0.61 | 0.68 / 0.70 | 예 |
| 보온 비율 낮음 (그 외 매질 25%) | 0.22 / 0.62 | 2.8 | 0.46 | 0.56 | 0.71 / 0.87 | 예 |
| 보온 비율 높음 (그 외 매질 65%) | 0.15 / 0.58 | 4.0 | 0.63 | 0.68 | 0.70 / 0.83 | 예 |
| 가공 배관 40% | 0.17 / 0.51 | 3.0 | 0.58 | 0.65 | 0.69 / 0.70 | 예 |
| 가공 배관 80% | 0.11 / 0.51 | 4.6 | 0.52 | 0.59 | 0.67 / 0.70 | 예 |
| 결함률 ×0.5 | 0.20 / 0.53 | 2.7 | 0.53 | 0.60 | 0.61 / 0.86 | 예 |
| 결함률 ×2 | 0.17 / 0.63 | 3.6 | 0.58 | 0.67 | 0.63 / 0.87 | 예 |
| 오래된 공장 (1970~2000년 설치) | 0.20 / 0.57 | 2.8 | 0.56 | 0.65 | 0.62 / 0.82 | 예 |
| 새 공장 (1990~2020년 설치) | 0.15 / 0.53 | 3.6 | 0.54 | 0.60 | 0.72 / 0.94 | 예 |
| 증기 비율 10% | 0.22 / 0.61 | 2.7 | 0.50 | 0.58 | 0.59 / 0.82 | 예 |
| 증기 비율 35% | 0.18 / 0.57 | 3.3 | 0.58 | 0.65 | 0.67 / 0.90 | 예 |
| 고소작업차 접근 | 0.15 / 0.51 | 3.5 | 1.01 | 1.12 | 0.68 / 0.70 | **아니오 (비용)** |
| 비계 단가 ×0.25 | 0.15 / 0.51 | 3.5 | 0.68 | 0.61 | 0.68 / 0.70 | 예 |
| 열화상을 맑은 낮에 촬영 | 0.15 / 0.50 | 3.4 | 0.54 | 0.61 | 0.68 / 0.76 | 예 |
| CUI 자리가 덜 젖어 있음 (61% → 20%) | 0.15 / 0.48 | 3.3 | 0.54 | 0.61 | 0.72 / 0.84 | 예 |

- **15개 중 14개에서** 드론+AI가 더 많이 찾고 더 쌉니다.
- **유일하게 뒤집힌 경우는 고소작업차 접근**입니다. 발견율은 3.5배 그대로지만 비용이 같아집니다(×1.01). 비용 이점은 높은 곳 접근 비용에 달려 있습니다([비용 모델](cost-model.md)).
- **발견율 배수는 모든 경우 2.7~4.6배**입니다. 결론 중 가장 덜 흔들립니다.
- 열화상을 맑은 낮에 찍거나 CUI 자리가 덜 젖어 있다고 가정해도 발견율은 0.51에서 0.48~0.50으로 조금만 떨어집니다. 열화상 단서가 약해져도 위험 지점 초음파와 PEC가 받쳐 줍니다.

**주의**
- 20 km에 5회만 돌린 결과라 칸마다 오차가 큽니다. 100 km 20회 결과(발견율 0.19 / 0.59)와 절대값이 다릅니다.
- "보온 비율" 변화는 보온 확률이 따로 정해진 증기·응축수·트레이싱 배관에는 적용되지 않습니다.
- 에너지 손실 발견에서 기본 조건의 드론+AI(0.70)가 다른 조건보다 낮은 것은 5회 평균의 흔들림입니다. 100 km 20회에서는 0.76 / 0.90입니다.

## 포스코 데이터가 들어오면 바꿀 입력

| 데이터 | 바꾸는 곳 | 효과 |
|---|---|---|
| 설비관리 시스템의 배관 목록 (길이, 매질, 관경, 재질, 설치 연도, 보온, 가공 여부, 위치) | `network` (가상망 대신 실제 목록) | 가상망 가정이 사라집니다 |
| 두께 측정 기록, 결함·누설 이력 | `defects.*.rate_per_km`, 부식 속도 | 결함률을 보정하고 결과를 검증합니다 |
| 스팀 트랩 목록과 점검 결과 | 트랩 위치, `defects.steam_trap.fail_prob` | 에너지 손실 계산이 실제 값이 됩니다 |
| 비계·고소작업차·보온 해체·외주 점검 단가 | `strategy.cost_*` | 비용 비교가 실제 값이 됩니다 |
| 현장 사진·열화상·초음파 파형 소량 | 모델 보정 ([학습 전략](learning-strategy.md)) | 합성 데이터와 실제의 차이를 잽니다 |

코드는 바꾸지 않고 설정만 바꿔 다시 계산합니다. 예를 들어 `python -m maek strategy --set strategy.cost_scaffold_krw=800000`처럼 실행합니다.
