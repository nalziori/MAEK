# PR 제목
안전 대응·작업자 초음파·드론 열화상과 메인 대시보드 통합

## 변경 결과
기존 배관에서 작업자는 초음파 검사를, 드론은 열화상 촬영을 수행하고 같은 배관 ID로 메인 대시보드에 결과를 표시한다. 안전 조건 미충족 시 검사 시작·재개를 차단하고 사고 발생 시 검사 중단과 대체 착륙 절차를 적용한다.

- Unity 안전 게이트·사고 대응, 작업자 UT 장비·동작, 드론 열화상 및 장면 생성 소스를 함께 포함한다.
- 기존 RGB·부식 / 열화상 화면 구조를 유지하며 촬영 사진과 간단한 온도 정보를 연결한다. UT는 파형과 분석 정보를 표시한다.
- 저장소의 기존 모델·프리팹·UT 패키지를 사용한다. 서비스 실행기는 저장소 상대 경로를 사용하고 UT 원본·패키지 해시를 확인한다.
- 생성 장면·실행 파일·Unity 캐시·로컬 증거 자료는 제외한다. 팀원은 메뉴에서 통합 장면을 생성하고 빌드한다.

## 실행
[통합 실행 안내](../unity-sensor-integration.md)의 순서대로 의존성 설치 → 서비스 실행 → Unity 통합 장면 생성 → Play 및 빌드를 진행한다.

## 이번 통합본 검증
- 실제 통합 C# 런타임 31개 / Editor 22개 컴파일: 오류 0건. 기존 경고 2건 유지.
- Python 연결 검사 17개, 실행기 검사 4개 통과.
- 실제 저장소 UT 정상·피팅 예제 2개 추론 및 4096개 파형 응답 확인.
- 열화상·UT JavaScript 단위 검사 통과.
- 기존 검증 작업본과 런타임 소스 일치, 633개 GUID 중복 없음, 필요한 프리팹 참조 확인.
- [검증 요약 JSON](unity-sensor-integration-verification.json)

## 남은 확인과 해석 범위
새 통합 체크아웃의 Editor Play-mode 및 Windows 실행본 재시연은 수행하지 않았다. 전체 RGB 완주 하네스는 프로세스 조회 권한 오류로 Unity 시작 전에 중단됐다. 병합 전 팀 환경에서 통합 장면과 전체 하네스를 재실행해야 한다. 과거 작업본 결과를 이번 통합본의 새 실행 증거로 제시하지 않는다.

초음파는 합성 파형 예제 재생, 열화상은 합성 표면 영상이다. 안전 대응은 모의 로직이며 실제 드론 사고 예방 성능이나 작업허가를 증명하지 않는다.
