# 프로젝트 계획서 기준 범위 정정

2026-11-09 최신 Google Docs 원문을 다시 읽고 사용자 지적에 따라 정정했다.

MAEK는 배관 영상·초음파·열화상에서 이상을 찾고, 어느 배관을 먼저 어떤 방법으로 확인할지
근거와 함께 제안하는 시스템이다. 가스 배관 전용으로 정의되지 않았다.
기본 가상망은 100 km, 9종 매질·10종 결함이며 실제 설비 목록이나 모든 매질에 대한 센서
검증 완료를 뜻하지 않는다. 적용성은 배관별 재질·온도·보온·접근 및 센서 조건으로 확인한다.

핵심 기능은 외부 부식·누설, UT 내부 균열, UT 두께·내부 피팅, IR/PEC 보온 배관 점검,
안전·조업 영향 기반 검사 후보 및 대시보드다. 현재 Unity의 RGB 시연 구현 상태와 구분한다.

## Unity 보완 방향 정정

- 기존 고로가스·냉각수·열풍 등 계통을 공통 배관 자산/관측 계약으로 관리한다.
- 대표 시연은 매질을 먼저 고정하지 않고 계획서의 세 판단 사례를 보여줄 배관으로 선택한다.
  A: 위험한 균열 의심→우선 검토. B: 흐린 관측→재촬영/추가 검사. C: 같은 위험 수준에서
  대체 공급이 없는 중요 공정 배관→먼저 확인할 이유 제시. 실제 진단 또는 명시적 모의 입력과 구분한다.
- 결과는 배관 번호 / 의심 이상 / 권장 검사 / 먼저 확인할 이유 / 정비 검토 시간대를 연결한다.
- 측정 품질과 필수 검사를 보존하고, 같은 안전 등급 안에서 조업 영향·시간·비용을 비교한다.
- BFG 26개·119개 촬영점이라는 기존 집계는 해당 계통의 사실일 뿐 전체 MAEK 범위를 결정하지 않는다.
- 전체 247개 회귀 검증은 유지하고, 세 판단 사례의 관측→진단→후속 검사→선정 근거를 우선 연결한다.
- 센서가 연결되지 않은 항목은 미구현/모의/미측정으로 표시한다. 정답은 평가에만 쓴다.

## 문서 우선순위

사용자의 최신 지시와 최신 프로젝트 계획서→제품 전체 범위→센서별 적용 계약→개별 공정 사례.
과거 모듈 문서의 가스 배관 강조를 전체 제품의 범위 제한으로 해석하지 않는다.
이번 작업은 로컬 규칙·검토 문서의 정정이며 Google Docs, Unity 장면과 EXE를 변경하지 않았다.
