# 대시보드 용어 기준

현장 작업자 관점과 UI 문구 관점의 서브에이전트 2명이 독립 검토한 뒤 적용한 기준입니다. 실제 현장 작업자 인터뷰를 대신하지 않습니다.

| 기존 | 적용 | 의미 |
|---|---|---|
| 조치 필요 | 점검 필요 | 의심 결과에 대한 추가 점검. 수리·교체가 확정된 상태 아님 |
| 부식 후보 | 부식 의심 | RGB 색상 규칙에서 표시한 의심 결과 |
| 후보 미관찰 / 의심 표시 없음 | 부식 의심 미검출 | 의심 표시를 검출하지 못함. 정상 판정 아님 |
| 결과 연결 | 결과 등록 | 선택 배관에 보고서 파일을 등록 |
| 결과 미접수 | 결과 미등록 | 이 브라우저 기기에 등록된 비파괴검사 결과가 없음 |
| 검토 대기 | 검토 필요 | 별도 검토가 필요함. 배정·승인 대기열을 뜻하지 않음 |
| 최근 현장검사 | 최근 비파괴검사 | 사람이 수행한 검사 결과 |
| 현장검사 기록 | 비파괴검사 기록 | 등록된 검사 결과를 검사 시각 순서로 표시 |
| 확인 지점 미연결 | 지점 높이 미확인 | 정확한 검사 지점의 높이가 현재 화면에 확인되지 않음 |
| 배관 경로 · 모델 지면 | 배관 높이 · 모델 기준 | 모델 지면 0m 기준 중심선의 높이 범위. 외곽 치수·발판 높이 아님 |
| 지도 전체 맞춤 | 전체 구역 보기 | 전체 모델 구역으로 화면 복귀 |
| 선택 배관 위치 맞춤 | 선택 배관으로 이동 | 선택한 배관을 지도 중앙에 표시 |
| 지도에서 위치 보기 | 지도에서 보기 | 선택 배관의 점검 지도로 이동 |
| 저장 촬영 | 저장 사진 | 정지 사진 자료를 표시 |
| 드론 촬영 근거 | 촬영 근거 ID | 펼쳤을 때 촬영 식별자 목록을 표시 |

## 상태와 수량

- 미연결: 해당 배관의 사진·분석 자료가 연결되지 않음.
- 미등록: 해당 배관의 작업자 검사 결과가 이 기기에 등록되지 않음.
- 미확인: 정확한 지점 높이처럼 현재 확인할 수 없는 정보.
- 의심 결과 수는 **건**으로 표시합니다. 공간 중복 제거가 확인되지 않아 고유 결함 위치 수인 **곳**으로 바꾸지 않습니다.
- 방문 완료를 검사 완료나 촬영 완료로 바꾸지 않습니다. 현재 위치·방문 경로는 저장 계획을 재구성한 시연 자료라는 설명을 유지합니다.
- 분석·검사 데이터, 배관 ID, 보고서 원문, 모델 좌표와 위험 판정 로직은 용어 변경의 대상이 아닙니다.
