# 비용 모델: 무엇을 기준으로 계산했나

## 계산식

비용은 시뮬레이션이 센 작업량에 단가를 곱한 합입니다(`maek/strategy.py`의 `cost_breakdown`).

- 작업량: 초음파 측정 지점, 보온재 해체 개소, 비계 수, 고소작업차 일수, 드론 비행 km, PEC 시간, 작업 시간
- 작업 시간: 순찰, 비계 설치·해체, 초음파 측정, 보온재 해체, PEC, 스팀 트랩 점검, 드론 비행, 영상 판독을 모두 더한 값
- 인건비 = 작업 시간 × 시간당 인건비

**단가는 전부 가정값입니다.** 출처가 있는 것은 근거를 적었지만, 포스코의 실제 단가는 모릅니다.

| 단가 | 값 | 근거·메모 |
|---|---|---|
| 초음파 1점 (장비·자료 처리) | 5만 원 | 가정. 인건비는 시간으로 따로 계산 |
| 보온재 해체·복구 1개소 | 20만 원 + 30분 | 가정 |
| 비계 1개 (높은 곳 구간당) | 200만 원 + 설치·해체 8시간 | 가정. 비계공 노임 281,939원/일(2026.1) 기준으로 넉넉히 잡음. 과대일 수 있음 |
| 고소작업차 1일 (선택) | 50만 원 + 1점당 20분 | 가정. 운전원 포함 임차 |
| 인건비 | 시간당 5만 원 | 비파괴시험공 노임 214,553원/일(약 2.7만 원/시간)에 간접비·이윤을 더한 수준으로 가정 |
| 드론 촬영 | km당 50만 원 | 가정 |
| 드론 접촉 초음파 추가 | 1점당 10만 원 | 가정 |
| AI 처리 | km당 2만 원 | 가정 |
| PEC 장비 | 시간당 3만 원 | 가정 |

노임은 2026년 1월 건설업 시중노임단가입니다. 원문(대한건설협회)이 아니라 [정리표](https://yellowit.co.kr/%ec%a7%81%ec%9e%a5%ec%9d%b8-%ec%97%b0%eb%a7%90%ec%a0%95%ec%82%b0-%ea%b5%ad%eb%af%bc%eb%82%b4%ec%9d%bc%eb%b0%b0%ec%9b%80%ec%b9%b4%eb%93%9c-%eb%85%b8%eb%8f%99%eb%b2%95/2026-construction-wage-rates-132-jobs/)에서 확인했습니다.

## 비용 내역 (기본망 100 km, 20회 평균, 억 원)

| 항목 | 사람+비계 | 드론 | 드론+AI |
|---|---|---|---|
| 비계 자재 | 23.03 | 12.75 | 9.23 |
| 인건비 | 6.16 | 4.29 | 3.37 |
| 보온재 해체·복구 | 4.24 | 4.24 | 3.52 |
| 초음파 1점 비용 | 1.91 | 1.91 | 1.64 |
| 드론 접촉 초음파 추가 | 0 | 1.03 | 0.92 |
| 드론 촬영·AI·PEC | 0 | 0.50 | 0.55 |
| **합계** | **35.35** | **24.73 (×0.70)** | **19.24 (×0.54)** |

- 사람+비계 방식 비용의 78%가 비계입니다. 자재 23.0억 원에 설치·해체 인건비 4.6억 원(9,213시간)이 더해집니다.
- 드론 방식에도 비계가 638개 남습니다. 높은 곳의 보온 배관은 사람이 보온재를 열어야 초음파를 잴 수 있기 때문입니다.

## 이전 계산(×0.27)에서 고친 것

| 고친 점 | 이전 | 지금 |
|---|---|---|
| 보온 배관 초음파 | 보온재 해체 비용·시간 없음 | 1개소 20만 원 + 30분, 사람만 가능 |
| 높은 곳 보온 배관 | 드론 접촉 초음파로 잼 | 드론은 보온재를 못 열어 비계 필요 |
| 초음파 1점 15만 원 | 측정 인건비와 이중 계산 | 5만 원 + 측정 시간 인건비 |
| 엘보 감육 | - | 보온 배관에서도 보온재를 열고 초음파로 잼(PEC는 작은 감육을 놓침) |

| 지표 (100 km, 20회) | 이전 사람+비계 / 드론 / 드론+AI | 지금 사람+비계 / 드론 / 드론+AI |
|---|---|---|
| 위험 결함 발견율 | 0.19 / 0.27 / 0.51 | 0.19 / 0.27 / 0.59 |
| 비용 비율 | 1 / 0.29 / 0.27 | 1 / 0.70 / 0.54 |
| 소요 일수 비율 | 1 / 0.41 / 0.38 | 1 / 0.78 / 0.62 |

드론의 비용 이점은 대부분 "보온 배관도 드론으로 잰다"는 잘못된 가정에서 나왔습니다. 드론+AI의 발견율은 열화상·PEC 단계가 더해져 오히려 올랐습니다.

## 가장 큰 변수: 높은 곳에 올라가는 방법

100 km, 10회 평균, 괄호는 사람+비계 대비입니다(`--set strategy.human_elevated_access=lift`).

| 접근 방식 | 사람+비계 비용 | 드론 | 드론+AI | 드론+AI 소요 일수 | 위험 결함 발견율 (사람 → AI) |
|---|---|---|---|---|---|
| 비계 | 35.4억 | 24.8억 (×0.70) | 19.4억 (×0.55) | ×0.62 | 0.20 → 0.61 |
| 고소작업차 | 8.6억 | 9.9억 (×1.15) | 8.8억 (×1.02) | ×1.14 | 0.20 → 0.61 |

- 고소작업차로 하루에 여러 곳을 돌 수 있으면 비용 이점은 사라집니다. 드론+AI는 비용이 비슷하고 시간은 14% 더 걸립니다. 드론만 쓰는 방식은 오히려 15% 비쌉니다.
- 발견율 약 3배는 접근 방식과 상관없이 유지됩니다.

**손익분기** (비계 방식 20회 결과에서 계산)
- 높은 곳 한 구간에 올라가는 비용을 비계 자재와 설치·해체 인건비를 합쳐 계산합니다. 지금 가정은 240만 원입니다.
- 드론+AI는 이 비용이 약 6.5만 원보다 비싸면 사람+비계보다 쌉니다.
- 드론만 쓰는 방식은 약 33만 원보다 비싸야 쌉니다.

## 단가 민감도

비계 방식에서 단가를 하나씩 ×0.5~×1.5로 바꾸면, 사람+비계 대비 비용 비율은 드론 0.66~0.77, 드론+AI 0.51~0.61입니다(`strategy/sensitivity.csv`). 가장 크게 움직이는 단가는 비계입니다.

## 발표할 때

- 중심 주장은 **"비슷한 비용으로 위험 결함을 약 3배 찾는다"**입니다. 비용은 "비계를 쓰는 현장이면 약 절반, 고소작업차를 쓰면 비슷"처럼 범위로 말합니다.
- 높은 곳 작업 시간(추락 위험)은 비계 방식 기준으로 비계 설치·해체 9,213시간이 3,692시간으로 줄어듭니다. 안전 주제와 바로 연결되는 근거입니다.
- 실제 단가가 생기면 바꿀 값은 비계, 보온재 해체, 외주 초음파 단가, 인건비입니다. `--set strategy.cost_scaffold_krw=...`처럼 바꿔 바로 다시 계산할 수 있습니다.
