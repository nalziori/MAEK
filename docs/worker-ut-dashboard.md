# 작업자 초음파 대시보드 연결

기존 대시보드의 현장 비파괴검사 영역과 배관 조회 상세에 Unity V5의 검사 단계와 A-scan 결과를 표시한다. Unity 소스와 동결 분석 모델은 이 변경에서 수정하지 않았다.

## 실행

1. 기존 `MAEK_Worker_UT_V5/Start_UT.cmd`로 Unity와 UT 분석 서비스를 실행한다.
2. 이 저장소의 `Start_UT_Dashboard.cmd`를 실행한다. 서버가 이미 실행 중이면 다시 실행할 필요가 없다.
3. `http://127.0.0.1:8894/index.html?tab=home&pipe=BF1-Q005`를 연다.
4. Unity에서 정상 조건 → 지상 시연 승인 → UT 검사 순서로 실행한다. 대시보드는 약 2초마다 기록을 확인한다.

다른 PC에서는 Python 경로를 조정하거나 저장소 루트에서 다음 명령을 사용한다. 분석 서비스 의존성은 기존 UT V5와 같다. 대시보드 서버 자체는 Python 표준 라이브러리만 사용한다.

```
python scripts/serve_ut_dashboard.py --port 8894
```

## 표시

- 배관 ID, 단계, 기록 시각, 합성 예제 표시
- 완료 시 정규화 A-scan 파형, 추정 주벽 두께, 피팅 의심 여부
- 상세: 예제 번호, 모델 점수·기준, 모델 이름, 결과 ID, 파형 출처
- 확대 파형: 샘플 인덱스 0~4095. 샘플링 주파수가 계약에 없으므로 시간 단위를 임의로 표시하지 않는다.
- 새 검사·보류·중단·서버 연결 실패 때 현재 파형과 두께를 숨긴다. 이전 완료 결과는 이전 검사 ID로 구분한다.
- 다른 배관에는 `미검사 · 연결 기록 없음`을 표시한다. Unity 고정 시연 지점 UT-01이며 실제 영상 표면과 정합한 위치로 소개하지 않는다.
- RGB·지도는 기존 저장 자료이며 열화상은 미연결 상태를 유지한다. 기존 수동 NDT 보고서 등록도 유지한다.

## 데이터 계약과 한계

`GET /api/ut`는 읽기 전용이며 127.0.0.1에서만 제공한다. 정해진 대시보드 파일과 설정된 V5 기록 폴더만 읽는다. 파일 경로를 요청 인자로 받지 않고 CORS를 열지 않는다.

V5 기록 폴더 기본값:

`%USERPROFILE%/AppData/LocalLow/MAEK/MAEK Worker UT V5/MAEK-worker-ut`

`schemaVersion=1`, `source=unity_v5_log_follow`, `producerLiveness=unknown`, `sessionId`, `pipes[pipeId]`를 반환한다. 최신 세션의 현재 단계와 `result`, 이전 결과 `previous`를 구분한다. 배관 목록에 없는 ID는 무시한다.

기존 V5 이벤트에는 요청 ID가 없기 때문에 동일 배관의 RESULT 이벤트 직후 0~2초 사이 기록된 결과 파일이 **정확히 하나일 때만** 연결한다. 파일 이름과 requestId, 배관 ID, 원본 예제 SHA256, 합성 표시, 작업허가 미판정, 파형 길이·유한값, 모델 점수·문턱·판정 일치, 두께 유효성을 확인한다. 모호하거나 불완전한 파일은 결과 확인 대기로 남긴다. 향후 이벤트에 requestId를 포함하면 시간 기반 대조를 명시적 ID 대조로 교체해야 한다.

이번 연결은 같은 PC의 로그 추적이다. 마지막 기록이 보인다고 Unity가 현재 실행 중이거나 센서가 살아 있다는 뜻은 아니다. 새 기록이 없으면 마지막 시각을 유지한다. 중앙 검사 이력·인증·실물 장비 수집·운영 배포 기능이 아니다.

기준 확인·신호 안정은 Unity의 모의 절차이며 실제 장비 교정이 아니다. 파형은 팀 합성 예제다. 추정 주벽 두께는 피팅 바닥의 최소 두께가 아니고, 무경보는 정상·안전·작업허가를 뜻하지 않는다.

## 검증

```
python -m unittest discover -s tests -p test_ut_dashboard_adapter.py -v
node dashboard/verify-ut-unit.mjs
```

API 시험은 누락·오연결·원본 불일치·비유한값·불완전 파일·복수 후보·이전 파일·새 검사·중단을 확인한다. UI 순수 함수 시험은 배관·출처·파형 검증, 단계별 파형 분리, 이전 기록 구분과 파형 표시를 확인한다.

실제 패키지 V5의 새 검사에서 이동·젤 도포·완료가 대시보드로 전달됐고, 예제 0의 4096개 파형과 4.58965856955mm 추정값이 연결됐다. 브라우저에서 파형 확대, 다른 배관 미검사, 배관 조회, 1024×768·1194×834·768×1024 문서 넘침 없음과 콘솔 오류 없음을 확인했다. 전체 기존 Puppeteer 시험이나 Unity 전체 RGB 경로 완주를 이번에 다시 실행한 것은 아니다.
