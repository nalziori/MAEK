# 배관 감육·균열의 열적 관측가능성: 1차 근거와 합성 범위

확인일: 2026-11-08. **확인한 문헌은 조건이 통제된 열적 여기에서 감육·균열을 관측할 수 있음을 보여준다. 이것이 수동 열화상으로 가스 배관의 모든 균열·감육을 식별할 수 있다는 근거는 아니다.** 현재 MAEK의 정합 영상 쌍 변화 분할과, 능동 NDT의 결함 판정·두께 역산은 구분한다. 이번 조사는 코드나 데이터를 변경하지 않았다.

## 2. 열전달 식의 근거와 경계조건

S5. [MIT OCW 2.051, Fall 2015 Equation Sheet, pp.1–2](https://ocw.mit.edu/courses/2-051-introduction-to-heat-transfer-fall-2015/e32f70f7e00f34953447b606cea0421f_MIT2_051F15_EqnSheet_Q2_v3.pdf)는 원통 방사방향 전도 저항 `ln(ro/ri)/(2πkL)`, 대류 저항 `1/(hA)`, 정상/비정상 열전도식과 복사 선형화 조건을 제시한다. **이 식의 출처가 있다는 사실은 임의로 고른 열전달계수·재료물성·경계조건의 현장 타당성을 보증하지 않는다.**

다음은 이 식과 현재 구현을 대조한 설계 판단이며 문헌의 현장 검증 결과가 아니다.

- 감육은 벽 전도 저항뿐 아니라 고정 외경 조건의 내경·내부 대류 면적도 바꾼다. 유체 온도·흐름·재질·열경계조건을 고정하지 않은 채 겉보기 온도만으로 두께를 유일하게 정할 수 있다고 가정하지 않는다.
- 내부/외부 대류계수는 유체·운전·주변 조건에 맞는 근거가 필요하다. `h`를 난수로 바꾸는 것은 민감도 시험이며 유동 계산이나 실측 보정이 아니다.
- 복사 열교환과 카메라가 받는 반사 복사는 구분한다. 방사율·주변 복사장을 바꾸면서 열수지를 그대로 유지한다면 **복사 관측만 바꾼 통제 실험**으로 표시한다. 실제 열평형이 함께 바뀌는 표면 모델이라고 설명하지 않는다.
- 보온재와 외장이 있으면 관측 표면은 금속벽이 아니라 외장이다. 금속 감육과 외장 온도 사이에 보온·접촉·대류·복사 조건이 개입한다. 능동 노출 금속 실험의 대비·면적 라벨을 그대로 이식하지 않는다.
- 정상상태 얇은 셸은 가열·냉각 시퀀스, 열용량, 실제 관 전체의 3차원 열확산을 검증하지 않는다. 전면 반원 스트립 양옆의 단열 경계는 뒤쪽 관벽을 재현한 것이 아니다. 경계 이동·영역 확대·둘레 연결 방식에 대한 민감도 검사를 별도로 해야 한다.
- 온도 구동력·외부 여기·초기 온도 불균일·발열이 모두 없는 평형 대조군에서는 두께가 다르다는 이유만으로 hotspot을 만들지 않는다. 이는 적용한 모델의 평형 검사이며 모든 현장 결함의 비관측성 증명이 아니다.

## 4. 다음 합성 데이터에 적용할 실행 제약

1. **수동 관측과 능동 NDT를 별도 데이터 계약으로 분리한다.** 수동 MAEK는 원인을 확정하지 않는 겉보기 열적 단서/변화 학습을 유지한다. 능동 결함 데이터는 열원·펄스·재질·위치·시간 샘플링·관측 방식까지 재현한 별도 실험으로만 추가한다.
2. **외부 열원의 존재만 흉내 내지 않는다.** 능동 자료를 쓰려면 입력 에너지·경계·초기조건과 시간응답 모델이 먼저 필요하다. 두 정지 영상 사이에 hotspot을 추가한 것을 펄스 검사나 균열 진행 시퀀스로 부르지 않는다.
3. **검출되지 않는 잠재 감육을 양성 관측으로 강제하지 않는다.** 잠재 형상, 잡음 없는 센서 관측, 잡음 있는 입력, 관측 가능/약함/무효 라벨을 분리한다. 열적 음성에서 필수 정밀검사를 유지하는 별도 경로 fixture도 보존한다.
4. **같은 관측을 만드는 다른 원인을 교차한다.** 반사·방사율·외부 열전달·운전 변화가 결함과 무관하게 생기는 대조군을 같은 장면 구조로 생성한다. 이를 구분하는 추가 정보가 없으면 원인 분류 라벨을 붙이지 않는다.
5. **수치 확인과 물리 검증을 구분한다.** 해석해·열평형·에너지 보존·격자 수렴은 구현 검증이다. 경계 조건/도메인 확대/별도 수치 모델 비교는 근사 민감도 확인이다. 제어 시편의 실제 온도응답 비교가 없으면 실측 타당성은 미확인으로 남긴다.
6. **논문의 검출 조건을 수동 데이터의 성능 목표로 복사하지 않는다.** S2의 d/t, S3의 온도 상승, S4의 균열 길이·여기 조건은 각각 해당 실험의 조건이다. MAEK의 최소 검출 균열·두께 오차·POD·사고 감소 수치로 변환할 수 없다.
