## 원문과 적용 범위

- Flyability Elios 3 공식 제품 페이지: https://www.flyability.com/elios-3
  `Limited Exposure` 절은 밀집·협소·어두운 환경의 접근 문제를 설명한다.
  적용: 장애물과 가림을 제거하지 않고 접근성 판정에 포함한다.
- 공식 광산 적용 안내 PDF: https://www.flyability.com/hubfs/Americas/Mining-infographic-es.pdf?hsLang=es
  `CARACTERÍSTICAS / AERONAVES`에 폭 48cm·높이 38cm가 표시된다.
  적용: 기존 초소형 모형 대신 폭 48cm급 검사용 드론의 크기를 참고한다.
  제품의 실제 비행 제어·SLAM·센서 성능·안전 적합성을 구현했다는 근거로 사용하지 않는다.

## 시뮬레이터의 가정

- 가상 기체는 반경 0.24m의 단순화된 구형 외피다. 실제 Elios 3 형상의 복제가 아니다.
- 별도 여유 거리 0.10m는 팀의 시연 가정이며 제조사 최소 안전거리나 현장 허가 기준이 아니다.
- 이동과 촬영점의 충돌 검사 반경은 합계 0.34m다.
- 설비를 먼저 배치한 뒤 기존 요구 촬영점의 간섭·대상 가림·연속 경로를 검사한다.
- 경로 탐색은 2m·1m·0.5m 격자, 격자별 8,000개 노드 한도로 제한한다.
  탐색 실패는 그 설정에서 경로를 확보하지 못했다는 뜻이다. 절대 접근 불가의 증명은 아니다.
- 포스코 실제 P&ID·현장 실측·비행 금지 구획·전파 음영·온도·풍속 자료는 확보되지 않았다.
  따라서 현재 판정은 고정 가상 배치와 명시한 크기·여유·시선·탐색 조건에 한정한다.

기존 247개 배관과 771개 요구 관측은 목록에서 삭제하지 않는다. 접근 가능한 관측만 예약하고,
나머지는 사유와 함께 검사 보류로 남긴다. 한 배관의 일부만 촬영한 경우에도 전체 검사 완료로
표시하지 않는다. 접근 가능성, 실제 관측 여부, 결함 후보 여부는 서로 다른 상태다.
