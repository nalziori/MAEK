# 피팅 노트북

`UT.ipynb`는 사용자가 제공한 Colab 수직 UT **피팅 1D-CNN** 실험 원본입니다. 균열 MLP 코드가 아닙니다.
노트북의 저장 출력은 그대로 보존했습니다. 23개 코드 셀의 execution_count가 비어 있으며 서로 다른 실행 시각의 경로가 있습니다. 이것만으로 결과가 틀렸다고 판단하지 않지만, 한 번의 순차 실행을 증명하지는 않습니다.

현재 입력 자료에 `cnn_followup.py`, `cnn_followup_recovery.py`, `cnn_lowfar.pt`, 최종 평가 NPZ 및 개별 판정 CSV가 없어 최신 피팅 결과를 이 패키지만으로 재실행할 수 없습니다. 저장 출력 확인과 원시 파형 재생 검증을 구분합니다.
셀 3의 `/content/MAEK`는 다른 셀의 실행별 저장소 경로와도 다릅니다. 원본을 수정하지 않았으므로 Colab에서 처음부터 실행하기 전 경로와 외부 파일을 확인해야 합니다.

피팅 MLP 재현은 상위 폴더의 `predict_ascan.py`와 `normal_ut_reviewed_v1/`를 사용합니다. 이 가중치로 최신 피팅 CNN 결과를 재현할 수는 없습니다.
