# 포항·광양 배관 길이 시나리오를 시뮬레이터 매질로 옮기는 방법

`posco_pipe_length_scenario_2026-11-06.json`은 포항·광양제철소의 배관 길이를 공개 자료(부지 면적, 고로 수, 해외 제철소 디지털 트윈 사례)로 추정한 합성 시나리오입니다. 실제 설비 목록이 아닙니다.
이 문서는 JSON의 11개 분류를 시뮬레이터의 9개 매질(`network.media_mix`)로 옮긴 규칙과, 그 규칙에 들어간 가정을 정리합니다.

## 1. JSON 시나리오 요약

| 사이트 | 부지 | 고로 | 총 길이 (fixed_topology / base / fixed_density) |
|---|---|---|---|
| 포항 | 8.9 km² | 3기 | 667 / 771 / 890 km |
| 광양 | 13.7 km² | 5기 | 828 / 1,065 / 1,370 km |

- 총 길이는 `500 km × (면적 / 5 km²)^p`입니다. p는 0.5(fixed_topology), 0.75(base), 1(fixed_density)입니다.
- 가스 7종은 부지 폭과 고로 수로 따로 계산합니다. 나머지 길이는 물·증기·공기 계열 4종에 고정 비율(0.48 / 0.16 / 0.14 / 0.22)로 나눕니다.
- **기준은 `base`입니다.** fixed_topology와 fixed_density는 민감도로만 씁니다.

## 2. 매질 대응

| JSON 분류 | 시뮬레이터 매질 | 근거·가정 |
|---|---|---|
| 고로가스(BFG), 코크스가스(COG), 전로가스(LDG) | `byproduct_gas_co` | 모두 CO를 포함한 부생가스입니다 |
| 수소, 천연가스 | `byproduct_gas_co` | **가정.** 시뮬레이터에 해당 매질이 없습니다. 피해등급이 같은 5등급 가연성 가스로 합칩니다 |
| 산소 | `oxygen` | 1:1 대응 |
| 질소·아르곤 | `nitrogen` | 1:1 대응. 둘 다 질식 위험입니다 |
| 냉각·공업용수 | `cooling_water` | 1:1 대응 |
| 폐수·처리수 | `cooling_water` | **가정.** 피해등급이 같은 1등급 저압 수계통입니다 |
| 증기·응축수 | `steam` 0.7 / `condensate` 0.3 | **가정.** JSON은 둘을 나누지 않습니다 |
| 압축공기·유압·화학약품 | `compressed_air` 0.9 / `pickling_acid_hf` 0.1 | **가정.** 불산 등 산세액의 비중을 알 수 없습니다 |
| (JSON에 없음) | `traced_process` 0 | JSON의 범위에 스팀 트레이싱이 따로 없습니다. 증기 대표 시나리오(`--scenario steam`)는 그대로 둡니다 |

수소·천연가스와 폐수는 새 매질로 추가하지 않았습니다. 새 매질을 넣으려면 공정, 온도, 재질, 보온, 결함률, 피해등급을 모두 새로 정해야 하고, 그 값은 전부 근거 없는 가정이 됩니다. 결과가 이 합치기 가정에 민감하다고 나오면 그때 새 매질로 나눕니다.

## 3. 기본망과 달라지는 점

| 매질 그룹 | 기본망 (`default.yaml`) | 포항 base | 광양 base |
|---|---|---|---|
| 피해등급 5 (CO가스·산소·불산) | 30% | 약 7.9% | 약 7.6% |
| 증기·응축수 | 20% | 12.9% | 12.9% |
| 물 계통 | 25% | 58.8% | 59.1% |
| 압축공기 | 15% | 18.2% | 18.3% |
| 질소 | 10% | 2.3% | 2.1% |

피해등급 5 비율은 CO가스, 수소·천연가스, 산소, 그리고 압축공기·유압·화학약품의 10%로 가정한 불산을 더한 값입니다.

- **고위험 매질 비율이 약 4분의 1로 줄어듭니다.** "놓친 고피해 위험 결함" 같은 절대 개수는 크게 줄어듭니다. 그래서 결과는 기본망과 비율(드론+AI ÷ 사람+비계)로 비교합니다.
- 물 계통 비율이 두 배 이상입니다. 물 계통은 보온 비율과 피해등급이 낮아 CUI와 고피해 결함 수가 줄어듭니다.
- 이 비율은 공개 자료로 만든 추정입니다. 포스코의 실제 배관 목록을 받으면 이 표가 가장 먼저 바뀝니다([프로젝트 설명서 6절](project-overview.md)).

## 4. 실행과 검증

- 시나리오 6개: `config/scenarios/{pohang,gwangyang}_{base,fixed_topology,fixed_density}.yaml`
- 변환 스크립트: `scripts/pipe_length_to_scenario.py`. 증기와 불산 비율을 인자로 바꿀 수 있습니다.
- 예시: `python -m maek strategy --scenario pohang_base --runs 10 --seed 1`
- 구성 효과와 규모 효과를 나눠서 봅니다.
  - 구성 효과: 같은 100 km에서 매질 구성만 바꿉니다(`--total-km 100`).
  - 규모 효과: 시나리오의 전체 길이로 돌립니다.
- 매질은 50 m 구간마다 무작위로 뽑습니다. 그래서 실제 길이는 목표 비율의 기댓값이며, 결과와 함께 목표 대비 실제 비율의 차이를 보고합니다.
- 민감도는 증기 비율 0.5 / 0.85, 불산 비중 0.05 / 0.25, p 세 가지로 봅니다.

결과는 [결과 문서](results.md)에 추가합니다.
