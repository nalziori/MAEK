MAEK 오프라인 시연 묶음
========================

실행 방법
1. 이 ZIP 전체를 원하는 폴더에 압축 해제합니다. (압축 프로그램 안에서 바로 실행하면 동작하지 않습니다)
2. START.bat 을 더블클릭합니다.
3. 검은 창이 뜨고 브라우저가 자동으로 열립니다. 검은 창은 시연하는 동안 열어 두고, 끝나면 닫습니다.

설치가 필요 없고 인터넷도 필요 없습니다. 영상과 데이터는 이 PC 밖으로 나가지 않습니다.

들어 있는 것
- 소개 화면: 표지, 팀, 시연 영상
- 시뮬레이션: 1고로 부생가스 배관 드론 점검 (약 2분)
- AI 모델 직접 돌려보기: 부식 분할, 열화상 열점 검출, 초음파 피팅 판정을 브라우저 안에서 실행

문제가 생기면
- "Windows의 PC 보호" 창이 뜨면: 추가 정보 > 실행 을 누릅니다.
- 브라우저가 열리지 않으면: 검은 창에 보이는 http://127.0.0.1:숫자/ 주소를 Chrome 또는 Edge 주소창에 붙여 넣습니다.
- Chrome 또는 Edge 최신 버전을 권장합니다. Internet Explorer 에서는 동작하지 않습니다.

구성
- site\    웹 화면과 AI 모델 파일 (ONNX)
- python\  Python 공식 배포판 (python.org embeddable package, 수정 없음)
- serve.py 이 PC 안에서만 접속되는 간이 웹 서버 (127.0.0.1)

소스 코드와 학습·평가 재현 방법: https://github.com/nalziori/MAEK  (docs/local-setup.md)
