# MAEK (맥)

**파이프의 맥을 읽는다.** POSCO AI Hackathon 2026 안전 주제 프로젝트입니다.

## 한 줄 소개

카메라와 열화상으로 낡은 배관의 이상을 먼저 찾고, 의심 지점만 초음파·PEC로 재서 점검 순서를 정합니다.

## 핵심 기능

| 기능 | 장비 | 찾는 것 |
|---|---|---|
| ① 부식 탐지 | 카메라 (드론, 로봇, CCTV) | 외부 부식, 보온재 아래 부식(CUI)의 겉 징후 |
| ② 내부 균열 탐지 | 초음파 사각 탐촉자 | 겉에서 안 보이는 균열, 파열 |
| ③ 두께 측정 | 초음파 수직 탐촉자 | 감육, 피팅, 남은 수명 |

증기·응축수·스팀 트레이싱 배관(대표 시나리오)에는 보조 장비 두 가지를 더 씁니다.

| 보조 장비 | 찾는 것 | 한계 |
|---|---|---|
| 열화상 (드론) | 젖은 보온재, 보온 손상, 증기 누설, 스팀 트랩 이상 | 알루미늄 외장은 방사율이 낮아 맑은 낮에 약함 |
| PEC (펄스 와전류) | 보온재를 뜯지 않고 평균 두께 | 탄소강만 가능. 풋프린트보다 작은 피트·감육은 놓침 |

## 동작 구조

1. 드론의 카메라·열화상으로 1차 선별합니다. 부식, 보온재 손상, 젖은 보온재, 누출 흔적을 찾습니다.
2. 고른 곳과 고위험 위치만 잽니다.
   - 보온 배관은 먼저 PEC로 보온재 위에서 잽니다.
   - PEC가 표시한 곳과 엘보처럼 감육이 몰리는 곳만 보온재를 열고 초음파로 잽니다.
   - 균열은 위험 순위가 높은 용접부를 사각 초음파로 봅니다.
3. 위험도로 점검 순서를 정합니다. 흐르는 물질(산소, 불산, CO), 사람 통행, 설치 연식을 씁니다.

## 설치와 실행

```bash
pip install -r requirements.txt
```

결과를 재현할 때는 스레드를 1개로 고정합니다. `OMP_NUM_THREADS=1`을 붙여 실행하세요.

| 명령 | 하는 일 | 예시 |
|---|---|---|
| `params-table` | 파라미터 표를 출력합니다. `--write`를 붙이면 `docs/params.md`를 갱신합니다. | `python -m maek params-table --write` |
| `network` | 가상 배관망, 구간, 결함을 만듭니다. | `python -m maek network --seed 0 --out data/network` |
| `ut` | 초음파 A-scan 데이터를 만들고 기준 성능을 출력합니다. | `OMP_NUM_THREADS=1 python -m maek ut --n 2000 --condition shifted --out data/ut` |
| `camera-jobs` | 카메라 촬영 작업(JSON)을 만듭니다. | `python -m maek camera-jobs --n 300 --seed 1 --out data/` |
| `render2d` | 촬영 작업을 이미지·마스크·YOLO-seg 라벨로 렌더링합니다. | `OMP_NUM_THREADS=1 python -m maek render2d --seed 1 --out data/` |
| `strategy` | 사람+비계, 드론, 드론+AI 세 방식을 비교합니다. | `python -m maek strategy --runs 20 --seed 1` |
| `evaluate` | 세 기능을 한 번에 평가합니다. | `python -m maek evaluate --out data/eval` |
| `onboard` | 탑재 장비의 연산 시간과 메모리를 측정합니다. | `python -m maek onboard --out data/eval` |
| `thermal` | 합성 열화상(16비트 온도 PNG)·마스크·라벨을 만들고 기본 탐지기를 평가합니다. | `python -m maek thermal --n 300 --condition train --out data/` |
| `thermal-pod` | 열화상 발견 확률(POD) 곡선을 적합합니다. | `python -m maek thermal-pod --n 600` |
| `eva` | 내부 피팅을 극치통계로 회로 단위 판정합니다. | `python -m maek eva --runs 10 --total-km 100` |
| `pit-prior` | 젖는 자리 스캔 가정이 틀릴 때의 피팅 발견율을 봅니다. | `python -m maek pit-prior --runs 10` |
| `sweep` | 환경 가정을 15가지로 바꿔 결론이 유지되는지 봅니다. | `python -m maek sweep --runs 5 --total-km 20` |

모든 명령에 두 옵션을 붙일 수 있습니다.
- `--scenario steam`: 증기 계통 대표 시나리오(`config/scenarios/steam.yaml`)를 덮어씁니다.
- `--set 키=값`: 파라미터 하나를 바꿉니다. 예: `--set strategy.human_elevated_access=lift`

전체 데이터는 `scripts/produce_data.py`로 한 번에 만듭니다.

```bash
OMP_NUM_THREADS=1 python scripts/produce_data.py
```

`--out`의 기본값은 `data/release`, `--seed`의 기본값은 1입니다. 규모는 `--ut-train`, `--img-train`, `--ir-train` 등으로 바꿀 수 있습니다. 4코어에서 약 15분 걸립니다.

## 결과 요약

아래 수치는 합성 데이터로 만든 기준선(규칙 기반 베이스라인)입니다. 실제 현장 성능이 아닙니다.
③은 같은 위치 16회 평균 A-scan과 피트 검출기(정합 필터 + CFAR + 작은 학습 분류기)를 쓴 값입니다(예전 규칙: 피트 검출률 0.924 / 0.045).
`train`은 학습 조건, `shifted`는 조명, 온도, 노이즈 등을 바꾼 학습에 없던 조건입니다.
자세한 내용은 [결과 문서](docs/results.md)에 있습니다.

| 기능 | 지표 | train | shifted |
|---|---|---|---|
| ① 부식 | 픽셀 IoU | 0.823 | 0.262 |
| ① 부식 | 결함 단위 hit율 | 0.991 | 0.311 |
| ② 균열 | 검출률 | 1.000 | 0.912 |
| ③ 두께 | 두께 MAE (mm) | 0.002 | 0.020 |
| ③ 두께 | 피트 검출률 (오경보율) | 1.000 (0.001) | 0.889 (0.007) |

열화상 기본 탐지기 (합성 열화상 300장, 학습 없음): 결함 단위 hit율, 흐린 날·야간 / 맑은 낮

| 대상 | hit율 |
|---|---|
| 젖은 보온재 | 0.78 / 0.34 |
| 보온 손상 | 0.93 / 0.84 |
| 증기 누설 | 0.59 / 0.51 |

점검 전략 비교, 기본망 100 km (20회 평균, 괄호는 사람+비계 대비):

| 지표 | 사람+비계 | 드론 (AI 없음) | 드론+AI |
|---|---|---|---|
| 위험 결함 발견율 | 0.192 | 0.270 | 0.587 |
| CUI 발견율 | 0.234 | 0.342 | 0.675 |
| 유동가속부식 감육 발견율 | 0.025 | 0.024 | 0.616 |
| 균열 발견율 | 0.000 | 0.000 | 0.162 |
| 내부 피팅 발견율 | 0.040 | 0.040 | 0.054 |
| 놓친 고피해 위험 결함 | 39.6 | 33.3 | 19.5 |
| 보온재 해체 | 2,122 | 2,122 | 1,761 |
| 비계 설치 | 1,152 | 638 | 462 |
| 소요 일수 | 385 | 299 (x0.78) | 238 (x0.62) |
| 비용 | 35.3억 | 24.7억 (x0.70) | 19.2억 (x0.54) |

증기 계통 대표 시나리오 20 km (`--scenario steam`, 20회 평균):

| 지표 | 사람+비계 | 드론 (AI 없음) | 드론+AI |
|---|---|---|---|
| 위험 결함 발견율 | 0.146 | 0.209 | 0.593 |
| CUI 발견율 | 0.226 | 0.335 | 0.701 |
| 젖은 보온재 발견율 | 0.10 | 0.55 | 0.81 |
| 발견한 에너지 손실 (연간) | 1.27억 | 1.43억 | 1.49억 |
| 비용 | 9.0억 | 8.7억 (x0.97) | 7.5억 (x0.83) |

- **발견율 약 3배가 가장 단단한 결과입니다.** 환경 가정을 15가지로 바꿔도 2.7~4.6배를 유지합니다([가정 흔들기](docs/robustness.md)).
- **비용 이점은 높은 곳 접근 방식에 달려 있습니다.** 비계를 쓰면 드론+AI가 약 절반이고, 고소작업차로 효율적으로 접근하면 비슷합니다(x1.02). 자세한 내용은 [비용 모델](docs/cost-model.md)에 있습니다.
- **보온 배관에서는 드론만으로 비용이 거의 줄지 않습니다.** 초음파를 재려면 사람이 보온재를 열어야 하기 때문입니다. 드론+AI는 열화상과 PEC로 열 곳을 골라 이 문제를 줄입니다.
- **내부 피팅은 여전히 낮습니다.** 피트 하나하나를 찾는 대신 회로 단위로 교체 여부를 판정하는 방법을 [피팅 전략](docs/pitting-strategy.md)에 정리했습니다.
- 단가와 작업 시간은 모두 가정값입니다.

탑재 장비 측정 (개발 PC CPU 1코어, 근사값):

- 부식 분할 640x640: 중앙값 64 ms. 5 fps 예산(200 ms) 안에 들어가지만 여유가 약 3배입니다. 보드가 3배 이상 느리면 못 맞춥니다.
- 부식 분할 320x320: 중앙값 15 ms.
- 균열, 두께 추정 (UT): 한 번에 약 1 ms입니다.
- 메모리: 최대 약 157 MB (기준선만 측정). 학습 모델은 아직 측정하지 않았습니다.

## 데이터 받기

학습한 카메라 모델은 [E4 Release](https://github.com/nalziori/MAEK/releases/tag/e4-20261109)에서
가중치·SHA256·평가 결과를 받을 수 있습니다. [모델 재현 안내](docs/model-reproducibility.md)에
고정 패키지 설치, 공식 가중치 평가, 재학습 한계와 실제 사진 데이터 version 3 다운로드 방법을 정리했습니다.

합성 데이터 v3(약 600MB)는 이 저장소의 `data-v3` 브랜치에 있습니다. 받는 방법과 조각 합치는 방법은 [data-v3 브랜치 README](https://github.com/nalziori/MAEK/tree/data-v3)에 있습니다. `data`(v1)와 `data-v2` 브랜치는 이전 모델의 데이터라 쓰지 마세요.

| 묶음 | 규모 |
|---|---|
| 배관망 정답 | 100km, 구간 2,000개, 특징 25,564개, 결함 1,249개(위험 200개) |
| ②③ 초음파 A-scan | 학습 10,000개, 어려운 조건 3,000개 |
| ① 카메라 이미지 | 학습 2,000장, 어려운 조건 400장 (마스크, YOLO-seg 라벨 포함) |
| 열화상 이미지 | 학습 1,000장, 어려운 조건 300장 (16비트 온도 PNG, 마스크, YOLO-seg 라벨) |
| 점검 전략 비교 | 기본망 20회, 증기 시나리오 20회, 단가 민감도, 피팅 가정 민감도, 환경 가정 15가지 |
| 피팅 극치통계 | 회로 판정 요약 10회 |

데이터 카드와 결과 표는 [구글 드라이브 MAEK 폴더](https://drive.google.com/drive/folders/1CSW6ENnyRrK0J1tF6CnAKn7gXxHfBkVz)에도 있습니다.

## 한계

- 모든 데이터는 합성입니다. 실제 점검 데이터로 검증하지 않았습니다.
- 탑재 장비 수치는 개발 PC CPU에서 잰 근사값입니다. 실제 보드 수치가 아닙니다.
- 비용 파라미터는 가정값입니다. 근거 자료가 없는 값은 `docs/params.md`에서 가정으로 표시합니다.
- 포스코의 실제 배관 길이, 매질 비율, 보온 비율, 연식은 모릅니다. 결과는 km당 값과 비율로 읽고, 가정을 바꾼 결과([가정 흔들기](docs/robustness.md))와 함께 보세요.
- 열화상과 PEC 모델은 단순화한 물리식입니다. 특히 알루미늄 외장의 반사와 PEC 풋프린트는 실제 장비로 보정해야 합니다.


## Unity 제철소 배관 검사 시연

기존 247개 배관과 산소 공급·소결 2차 집진 17스팬의 가상 검사 환경은
[Unity 실행·검증·Windows 패키징 안내](docs/unity-checkout.md)를 참고하세요.
라이브 분석은 합성 장면의 RGB 부식 색상 기준선이며 현장 안전 판정이나 균열 예측이 아닙니다.
